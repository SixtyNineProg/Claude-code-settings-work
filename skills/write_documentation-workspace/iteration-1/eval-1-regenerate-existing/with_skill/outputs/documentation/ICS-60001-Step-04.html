Идентификатор ICS-60001-Step-04
Определение Редактирование списков типов документов (пользовательское действие)
Пользователь Исполнитель
Входные данные
  • Задача documentTypePolicyEditor из очереди "ICS-60001 Document type policy editor" (initialData: allowedDocList, deniedDocList, transactionName)
Основной путь
  1. Исполнитель открывает форму Action "document-type-policy-editor" по ссылке из письма/личного кабинета;
  2. Исполнитель просматривает списки разрешённых и запрещённых типов документов и комментарии к ним;
  3. Исполнитель редактирует комментарии, включает/отключает типы документов для проверки;
  4. Исполнитель сохраняет изменения — задача обновляется с тегом policyUpdated и новым initialData.
Альтернативные пути —
Выходные данные
  • Обновлённая задача в очереди "ICS-60001 Document type policy editor" с тегом policyUpdated
Дополнительные требования Пользовательское действие "document-type-policy-editor" должно быть опубликовано в Оркестраторе; ссылка указана в параметре documentTypePolicyEditorActionLink.
Возможные исключения ICS-60001-EX-04
