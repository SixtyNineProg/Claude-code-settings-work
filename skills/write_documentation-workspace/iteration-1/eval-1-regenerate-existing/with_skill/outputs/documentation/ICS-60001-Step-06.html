Идентификатор ICS-60001-Step-06
Определение Подготовка выборки для проверки
Пользователь Bot
Входные данные
  • accountingDocumentPositions
  • allowedDocList (из транзакции) либо ресурс document_type_classification
Основной путь
  1. Бот загружает позиции и множество allowedDocTypes (из allowedDocList или, при пустом списке, из ресурса document_type_classification);
  2. Бот группирует позиции по номеру документа в AccountingDocumentGroup;
  3. Бот фильтрует группы по разрешённым типам документов (documentType ∈ allowedDocTypes);
  4. Бот рассчитывает размер выборки getDocsCountForProceed: ≤12 — 2, ≤52 — 5, ≤365 — 15, иначе 25;
  5. Бот случайным образом отбирает sampleSize групп, сортирует по первому вхождению документа;
  6. Бот собирает уникальные имена пользователей (sampleOwners) и сохраняет sampleDocuments, sampleOwners, filteredDocuments в транзакцию.
Альтернативные пути —
Выходные данные
  • sampleDocuments — отобранные для проверки группы документов
  • sampleOwners — уникальные SAP-логины владельцев проводок
  • filteredDocuments — все группы разрешённых типов
Дополнительные требования —
Возможные исключения ICS-60001-EX-06
