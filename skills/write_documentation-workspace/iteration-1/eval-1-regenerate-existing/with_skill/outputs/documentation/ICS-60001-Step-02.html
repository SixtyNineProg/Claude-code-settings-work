Идентификатор ICS-60001-Step-02
Определение Получение данных отчёта из SAP
Пользователь Bot
Входные данные
  • InitParameters (sapTransactionCode, sapMocked, testExcelPath, sharepointBaseUrl, sharepointProject, sharepointBasePath)
  • resolvedReportEndDate
  • exchangeRate (порог существенности)
  • workInputDataFolderPath, workScreenshotsFolderPath
Основной путь
  1. Бот подключается к SharePoint (sharepoint_credentials);
  2. При sapMocked=false Бот открывает SAP-сессию (SapGuiAutomation.connectViaShortcutDesc, ресурс sap_settings, sap_credentials), запускает транзакцию sapTransactionCode, заполняет год/месяц/порог, делает скриншоты входа, первой и последней страницы отчёта;
  3. Бот экспортирует отчёт в Excel (SHIFT+F9) во временную папку;
  4. Бот загружает Excel и книгу скриншотов в папки workInputData и workScreenshots SharePoint;
  5. При sapMocked=true Бот скачивает тестовый Excel из testExcelPath и загружает его в workInputData;
  6. Бот парсит Excel (Poiji) в список AccountingDocumentPosition и сохраняет в транзакцию.
Альтернативные пути При sapMocked=true SAP не открывается — используется тестовый Excel из SharePoint.
Выходные данные
  • accountingDocumentPositions — список позиций бухгалтерских проводок из отчёта SAP
Дополнительные требования На рабочем месте Бота должен быть установлен SAP Logon / SAP GUI; ресурс sap_settings должен содержать systemName, client, language.
Возможные исключения ICS-60001-EX-02, ICS-60001-EX-03
