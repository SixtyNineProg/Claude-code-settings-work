Идентификатор ICS-60001-Step-05
Определение Сохранение списков типов документов
Пользователь Bot
Входные данные
  • Задача из очереди "ICS-60001 Document type policy editor" с тегом policyUpdated (initialData: allowedDocList, deniedDocList)
  • InitParameters (emailRecipients)
Основной путь
  1. Бот читает из очереди "ICS-60001 Document type policy editor" задачу с тегом policyUpdated;
  2. Бот извлекает allowedDocList и deniedDocList из initialData (Map или JSON-строка);
  3. Бот формирует множества allowedCodes/deniedCodes, комментарии и список DictionaryList (DocumentTypeEntry: code, allowed, comment);
  4. Бот сохраняет dictionaryList в транзакцию;
  5. Бот обновляет ресурсы Оркестратора: document_type_classification (JSON) и document_type_comments (JSON);
  6. Бот отправляет уведомление task_completed (Обновление справочника) на emailRecipients.
Альтернативные пути Если initialData пришёл как строка "[object Object]" — Бот выбрасывает BusinessException с пояснением, что форма отправила невалидный JSON.
Выходные данные
  • dictionaryList — итоговый справочник типов документов (code, allowed, comment)
  • Обновлённые ресурсы document_type_classification и document_type_comments
Дополнительные требования —
Возможные исключения ICS-60001-EX-04, ICS-60001-EX-05
