Идентификатор ICS-60001-Step-09
Определение Обработка документа (пользовательское действие)
Пользователь Исполнитель / Владелец проводки
Входные данные
  • Задача documentReview из очереди "ICS-60001 Document review" (initialData: sampleDoc, bearerToken)
Основной путь
  1. Владелец/Исполнитель открывает форму Action "document-review" по ссылке из письма/личного кабинета;
  2. Просматривает информацию о документе и его позициях;
  3. Загружает файл подтверждающего документа (при наличии);
  4. Выбирает статус проверки ("OK" или "NOT OK") и вводит комментарий;
  5. Сохраняет результат — задача обновляется с userInput (status, comment, uploadedFileGuid, uploadedFileName).
Альтернативные пути —
Выходные данные
  • Задача в очереди "ICS-60001 Document review" с userInput (status, comment, загруженный файл)
Дополнительные требования Пользовательское действие "document-review" должно быть опубликовано в Оркестраторе; ссылка указана в параметре documentReviewActionLink.
Возможные исключения —
