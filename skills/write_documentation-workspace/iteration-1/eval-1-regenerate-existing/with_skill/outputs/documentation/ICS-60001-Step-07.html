Идентификатор ICS-60001-Step-07
Определение Обогащение выборки владельцами
Пользователь Bot
Входные данные
  • sampleOwners — SAP-логины владельцев проводок
  • InitParameters (mimCommand, mimUrl, mimAccountsAttributesToGet, mimPersonsAttributesToGet, mimAccountsFilter, mimPersonsFilter, mimCommandTimeoutMs, controllerEmail)
  • mim_credentials
Основной путь
  1. Бот открывает PowerShell-сессию и выполняет две команды MIM (mimCommand) для аккаунтов и сотрудников с фильтрами и атрибутами из InitParameters;
  2. Бот строит карту sapLogin → personId (по DisplayedOwner/vc_AppAccountName) и карту personId → атрибуты сотрудника;
  3. Бот для каждого sampleOwner находит personId и запись сотрудника, формирует OwnerContact (email, sapLogin, fullName, active по vc_EmployeeStatus="Активен");
  4. Бот сохраняет ownersEnriched в транзакцию;
  5. Если задан controllerEmail, Бот ищет сотрудника с таким email и сохраняет controllerName и controllerPosition (vc_JobTitleRus).
Альтернативные пути Владельцы без сопоставления с personId или без записи сотрудника пропускаются; если persons пуст — контролёр не обогащается.
Выходные данные
  • ownersEnriched — список OwnerContact с email, sapLogin, fullName, active
  • controllerName, controllerPosition — данные контролёра (если найден)
Дополнительные требования На рабочем месте Бота должен быть доступен PowerShell; ресурс mim_credentials должен быть настроен; MIM-сервис должен быть доступен по mimUrl.
