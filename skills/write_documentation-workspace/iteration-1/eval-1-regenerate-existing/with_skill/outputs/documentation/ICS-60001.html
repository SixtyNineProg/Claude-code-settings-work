Общее описание

Процесс "ICS-60001" предназначен для автоматизации контроля корректности ручных бухгалтерских проводок: бот извлекает параметры, получает данные отчёта из SAP, рассчитывает порог существенности, формирует структуру папок в SharePoint, подготавливает и сохраняет списки типов документов, формирует выборку проводок для проверки, обогащает её владельцами из MIM, рассылает задания исполнителям и финализирует результаты с публикацией отчёта и технического архива.

С целью трассировки требований общим артефактам по данному процессу присваивается индекс "ICS-60001".

Документация по роботизируемому процессу состоит из следующих разделов:

  • ICS-60001: История изменений
  • ICS-60001: Инструкция по развертыванию
  • ICS-60001-PDD: Process Design Document / Документ проектирования процесса
  • ICS-60001-TD: Test Documentation / Тестовая документация
  • ICS-60001-UG: User Guide / Руководство пользователя
