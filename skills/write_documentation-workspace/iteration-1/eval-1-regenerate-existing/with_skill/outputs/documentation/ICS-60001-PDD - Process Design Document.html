Описание процесса

Назначение бизнес-процесса
Автоматизация контроля корректности ручных бухгалтерских проводок: извлечение параметров и данных отчёта из SAP, расчёт порога существенности по курсу валюты, формирование структуры папок в SharePoint, подготовка и сохранение списков типов документов с участием пользователя, формирование выборки проводок, обогащение её владельцами из MIM, рассылка заданий исполнителям и финализация результатов с публикацией отчёта и технического архива.

Упрощенная BPMN схема бизнес-процесса

Файл-исходник: ICS-60001.bpm

Выходные данные бизнес-процесса
Excel-отчёт о результатах проверки (ICS-60001.xlsx), технический архив (zip), письмо с итоговым статусом контроля и ссылкой на результаты в SharePoint.
