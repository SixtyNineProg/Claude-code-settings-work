Идентификатор ICS-60001-Step-10
Определение Финализация и публикация результатов
Пользователь Bot
Входные данные
  • Задачи из очереди "ICS-60001 Document review" с userInput
  • sampleDocuments, filteredDocuments, accountingDocumentPositions, dictionaryList, exchangeRate, resolvedReportEndDate
  • workInputDataFolderPath, workScreenshotsFolderPath, workingFolderPath, workOtherEvidenceFolderPath, technicalArchiveFilename
  • InitParameters (sharepointBaseUrl, sharepointProject, sharepointBasePath, emailRecipients)
  • sharepoint_credentials
Основной путь
  1. Бот подключается к SharePoint и читает из очереди "ICS-60001 Document review" все задачи с userInput;
  2. Бот парсит DocumentReviewResult (sampleDoc + userInput) и сопоставляет user input по номеру документа;
  3. Бот формирует отчёт ICS-60001.xlsx (TemplateResultsWorkbookBuilder) по позициям, отфильтрованным группам, выборке, справочнику, результатам проверки, курсу и числу проверенных документов;
  4. Бот загружает ICS-60001.xlsx в папку working SharePoint;
  5. Бот скачивает прикреплённые доказательства из Оркестратора (files.download по guid) и загружает их в папку workOtherEvidence;
  6. Бот скачивает из SharePoint исходный ZFI_FCRP1.xlsx и screenshots.xlsx;
  7. Бот собирает технический архив (zip) с уникальными именами записей: ICS-60001.xlsx, input data/, screenshots/, other evidence/;
  8. Бот загружает zip в папку working SharePoint;
  9. Бот отправляет task_completed (Проверка ручных проводок) и process_completed с итоговым статусом контроля и ссылкой на результаты.
Альтернативные пути Ошибки скачивания отдельных доказательств/файлов логируются как warnings и не останавливают шаг; если хотя бы один userInput.status="NOT OK" — controlStatus указывает на расхождения.
Выходные данные
  • ICS-60001.xlsx — отчёт о результатах проверки в папке working SharePoint
  • zip технического архива в папке working SharePoint
  • Доказательства в папке workOtherEvidence SharePoint
  • Письмо task_completed (Проверка ручных проводок)
  • Письмо process_completed с итоговым статусом и ссылкой на результаты
Дополнительные требования Шаблон ICS-60001.xlsx должен быть доступен TemplateResultsWorkbookBuilder; ресурс sharepoint_credentials должен иметь права на загрузку/выгрузку.
Возможные исключения ICS-60001-EX-09

Приложения

Пример письма с результатом работы
Письмо process_completed: тема — стандартный шаблон завершения процесса, тело содержит итоговый controlStatus ("В ходе сверки расхождений не обнаружено." либо "В ходе сверки обнаружены расхождения.") и ссылку controlResultsLink на папку с результатами в SharePoint.
