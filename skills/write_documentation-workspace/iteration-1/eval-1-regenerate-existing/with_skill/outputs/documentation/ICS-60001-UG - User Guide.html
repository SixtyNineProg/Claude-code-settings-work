Краткое описание процесса

Упрощенная BPMN схема бизнес-процесса

Описание шагов процесса с точки зрения действий Исполнителя

Шаг (со ссылкой на PDD) Наименование Действия Исполнителя Действия Bot
ICS-60001-Step-01 Инициализация параметров и создание структуры папок
  • Получает уведомление о старте процесса.
  • Загружает InitParameters, вычисляет дату отчёта, получает курс валюты и рассчитывает порог существенности;
  • Создаёт структуру папок периода в SharePoint (UnifiedFoldersUtil.monthly);
  • Отправляет уведомление process_started.
ICS-60001-Step-02 Получение данных отчёта из SAP Исполнитель не участвует (процесс выполняется автоматически)
  • Выгружает отчёт ZFI_FCRP1 из SAP (или тестовый Excel при sapMocked=true);
  • Загружает Excel и книгу скриншотов в SharePoint;
  • Парсит позиции в accountingDocumentPositions.
ICS-60001-Step-03 Подготовка списков типов документов
  • Получает уведомление task_assigned с ссылкой на редактор списков типов документов.
  • Загружает классификатор и комментарии, формирует allowed/denied/unclassified списки;
  • Создаёт задачу documentTypePolicyEditor в очереди "ICS-60001 Document type policy editor";
  • Отправляет task_assigned (Обновление справочника).
ICS-60001-Step-04 Редактирование списков типов документов
  • Открывает форму "document-type-policy-editor";
  • Редактирует комментарии и включённые/отключённые типы документов;
  • Сохраняет изменения (задача получает тег policyUpdated).
  • Ожидает завершения пользовательского действия в очереди "ICS-60001 Document type policy editor".
ICS-60001-Step-05 Сохранение списков типов документов
  • Получает уведомление task_completed (Обновление справочника).
  • Читает обновлённую задачу с тегом policyUpdated;
  • Обновляет ресурсы document_type_classification и document_type_comments;
  • Сохраняет dictionaryList в транзакцию.
ICS-60001-Step-06 Подготовка выборки для проверки Исполнитель не участвует
  • Группирует позиции по документам, фильтрует по allowed типам;
  • Случайно отбирает выборку и собирает уникальных владельцев.
ICS-60001-Step-07 Обогащение выборки владельцами Исполнитель не участвует
  • Запрашивает аккаунты и сотрудников MIM через PowerShell;
  • Формирует OwnerContact (email, active) и определяет контролёра.
ICS-60001-Step-08 Рассылка заданий исполнителям
  • Получает письмо multitask_new с таблицей проводок и сроком ответа;
  • Контролёр получает task_assigned (Проверка ручных проводок).
  • Отправляет multitask_new активным владельцам и task_assigned контролёру;
  • Создаёт задачи documentReview в очереди "ICS-60001 Document review".
ICS-60001-Step-09 Обработка документа
  • Открывает форму "document-review";
  • Просматривает документ и позиции, загружает подтверждающий файл;
  • Выбирает статус ("OK"/"NOT OK") и комментарий, сохраняет результат.
  • Ожидает завершения пользовательского действия в очереди "ICS-60001 Document review".
ICS-60001-Step-10 Финализация и публикация результатов
  • Получает task_completed (Проверка ручных проводок) и process_completed с итоговым статусом и ссылкой на результаты.
  • Формирует ICS-60001.xlsx и технический архив (zip);
  • Загружает результаты и доказательства в SharePoint;
  • Отправляет task_completed и process_completed.

Работа Исполнителя с исключениями

№ Описание Тип исключения Действие Исполнителя при наступлении
ICS-60001-EX-01 Ошибка создания структуры папок в SharePoint Системное
  • Получить уведомление об ошибке: "Ботопроцесс ICS-60001. Во время выполнения ботопроцесса возникла ошибка. Ботопроцесс остановлен.";
  • Проверить доступность SharePoint и учётные данные sharepoint_credentials;
  • Ожидать информации от support группы по решению проблемы в рамках задачи RPA либо скоординировать действия самостоятельно.
ICS-60001-EX-02 Ошибка выгрузки отчёта из SAP или работы с SAP GUI сессией Системное
  • Получить уведомление об ошибке остановки процесса;
  • Проверить доступность SAP, ресурс sap_settings и sap_credentials;
  • При необходимости запустить процесс в режиме sapMocked=true для тестового прогона.
ICS-60001-EX-03 Ошибка создания скриншота или формирования книги скриншотов Системное
  • Получить уведомление об ошибке;
  • Проверить, что рабочее место Бота допускает захват экрана (Robot) и не заблокировано.
ICS-60001-EX-04 Некорректные данные из формы редактора списков типов документов (получен "[object Object]" вместо JSON) Бизнес
  • Получить уведомление об ошибке;
  • Открыть форму "document-type-policy-editor" повторно и сохранить изменения ещё раз;
  • При повторении ошибки сообщить support группе для проверки публикации Action.
ICS-60001-EX-05 Ошибка сохранения списков типов документов в ресурсы Оркестратора Системное
  • Получить уведомление об ошибке;
  • Проверить наличие и права на ресурсы document_type_classification и document_type_comments;
  • Ожидать информации от support группы.
ICS-60001-EX-06 Ошибка подготовки выборки проводок для проверки Системное
  • Получить уведомление об ошибке;
  • Проверить, что accountingDocumentPositions корректно выгружены на предыдущем шаге.
ICS-60001-EX-07 Ошибка обогащения выборки владельцами через MIM/PowerShell Системное
  • Получить уведомление об ошибке;
  • Проверить доступность MIM-сервиса (mimUrl) и ресурс mim_credentials;
  • Проверить, что PowerShell доступен на рабочем месте Бота.
ICS-60001-EX-08 Ошибка рассылки заданий исполнителям и создания задач documentReview Системное
  • Получить уведомление об ошибке;
  • Проверить доступность API Sherpa и ресурс sherpa_api_credentials;
  • Проверить существование очереди "ICS-60001 Document review" в Оркестраторе.
ICS-60001-EX-09 Ошибка финализации и публикации результатов в SharePoint Системное
  • Получить уведомление об ошибке;
  • Проверить доступность SharePoint и наличие шаблона ICS-60001.xlsx;
  • Ожидать информации от support группы.
