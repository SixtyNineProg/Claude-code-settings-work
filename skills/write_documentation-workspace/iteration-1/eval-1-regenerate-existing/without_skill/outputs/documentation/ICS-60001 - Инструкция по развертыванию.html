1

Проверить, что все элементы процесса соответствуют принятому стилю
2

Подготовить необходимые файлы и выполнить перенос процесса на прод согласно общей инструкции
3

Проверяем/Создаем Ресурсы типа Credential на целевой среде (без них процесс не сможет авторизоваться в системах):

  • sherpa_api_credentials — токен для работы с API Sherpa (используется в шаге SendMultitaskNotificationStep для создания заданий documentReview)
  • sap_credentials — доступ к SAP (SAP GUI и сервис курсов валют)
  • sharepoint_credentials — доступ к SharePoint
  • proxy_credentials — прокси для внешних соединений (используется сервисом CurrencyRates)
  • mim_credentials — доступ к MIM (PowerShell-запросы аккаунтов и сотрудников)
4

Проверяем/Создаем Ресурсы типа Text на целевой среде:

  • ics60001_init_params — параметры инициализации (см. PDD, раздел «Конфигурируемые параметры»)
  • ics60001_email_templates — шаблоны email-уведомлений (содержит шаблон multitask_new)
  • currency_rates_config — конфигурация получения курсов валют (CurrencyRatesConfig)
  • document_type_comments — справочник комментариев к типам документов (Map<String,String>)
  • document_type_classification — классификатор типов документов (allowedDocTypes/deniedDocTypes)
  • sap_settings — настройки SAP GUI (systemName, client, language) для шага GetSapReportDataStep
5

Опционально Проверяем/Создаем папку в Хранилище файлов и загружаем файл-шаблон отчёта ICS-60001.xlsx (используется TemplateResultsWorkbookBuilder на шаге финализации). Шаблон содержит листы ZFI_FCRP1, Выборка, Популяция, Справочник и именованные ячейки Rate, Materiality_level, Rate_limit, Date_end, Date_current, All_docs, All_docs_to_check, Docs_to_check, Checked_docs.
6

Опционально Проверяем/Создаем очереди задач в Orchestrator:

  • ICS-60001 Document type policy editor — задания на редактирование справочника типов документов
  • ICS-60001 Document review — задания на проверку документов выборки
7 Опционально Проверяем/Создаем Триггеры

Дополнительные действия:

  1. Проверить доступ к SAP (включая SAP GUI и сервис курсов валют) и SharePoint с целевой среды;
  2. Проверить корректность email-шаблонов (ics60001_email_templates, шаблон multitask_new) и параметров интеграции (mimUrl, mimCommand, фильтры MIM);
  3. Проверить доступность PowerShell и возможность выполнения команд MIM с целевой среды (шаг OwnersEnrichmentStep использует com.profesorfalken.jpowershell);
