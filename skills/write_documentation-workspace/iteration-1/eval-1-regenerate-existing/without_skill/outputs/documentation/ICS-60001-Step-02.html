Идентификатор ICS-60001-Step-02
Определение Получение данных отчёта из SAP и парсинг позиций документов
Класс Java by.a1.ics60001.steps.GetSapReportDataStep
Пользователь Bot
Входные данные
  • Transaction: resolved.report.end.date, exchange.rate, work.input.data.folder.path, work.screenshots.folder.path
  • Credentials: sharepoint_credentials, sap_credentials (при реальном режиме)
  • Ресурс sap_settings (при sapMocked=false)
  • InitParameters: sapTransactionCode, sapMocked, testExcelPath, параметры SharePoint
Основной путь
  1. Бот подключается к SharePoint и получает resolvedReportEndDate и ExchangeRate из транзакции;
  2. Из даты вычисляются year и month для SAP-параметров;
  3. Если sapMocked=false:
    • через SapGuiAutomation.connectViaShortcutDesc подключается к SAP (с пред-завершением процессов saplogon.exe/saplgpad.exe);
    • запускает транзакцию sapTransactionCode, заполняет поля P_GJAHR=year, P_MONTH=month, P_SUM=materialityThreshold (десятичный разделитель «,»);
    • делает скриншоты: _input, _output, _output_last (через Robot);
    • выполняет экспорт (Shift+F9) в temp-файл sap_export_<ms>.xlsx;
    • загружает Excel и собранный workbook со скриншотами screenshots.xlsx в SharePoint (папки input data / screenshots, стратегия OVERWRITE).
  4. Если sapMocked=true: бот скачивает тестовый Excel из SharePoint по testExcelPath и загружает его в папку input data как <sapTransactionCode>.xlsx;
  5. Бот парсит Excel через Poiji.fromExcel (sheetIndex=0, preferNullOverDefault) в список AccountingDocumentPosition (поля: № документа, БЕ, Позиция, Валюта транзакции, Номер счета, Сумма ВТ, Сумма ВВ, Дата проводки, Имя пользователя, Текст, Операция, Автоматически созданная позиция, Красное сторно, Вид документа, Текст ЗаголовДокум, Код транзакции);
  6. Бот сохраняет accounting.document.positions в транзакцию.
Альтернативные пути Ошибка авторизации/сессии SAP (SessionException), ошибка парсинга Excel или загрузки в SharePoint — бот выбрасывает BusinessException («SAP export failed»), процесс завершается с ошибкой.
Выходные данные
  • Transaction: accounting.document.positions (List<AccountingDocumentPosition>)
  • SharePoint: <sapTransactionCode>.xlsx в папке input data, screenshots.xlsx в папке screenshots (при реальном режиме)
Дополнительные требования На машине-исполнителе должен быть установлен SAP GUI (для sapMocked=false); JVM с доступом к библиотекам SAP Java Connector. Скриншоты делаются через java.awt.Robot — требуется активная сессия рабочего стола.
