Идентификатор ICS-60001-Step-10
Определение Финализация и публикация результатов: итоговый отчёт, технический архив, уведомления
Класс Java by.a1.ics60001.steps.FinalizeAndPublishResultsStep (формирование workbook — TemplateResultsWorkbookBuilder)
Пользователь Bot
Входные данные
  • Transaction: sample.documents, documents.filtered, accounting.document.positions, dictionary.list, exchange.rate, resolved.report.end.date, work.working.folder.path, work.input.data.folder.path, work.screenshots.folder.path, work.other.evidence.folder.path, work.technical.archive.filename
  • Очередь «ICS-60001 Document review» (задачи с userInput)
  • Файл-шаблон ICS-60001.xlsx (из Storage/ресурсов)
  • Credentials: sharepoint_credentials
  • InitParameters: параметры SharePoint, sapTransactionCode, emailRecipients, controlName
Основной путь
  1. Бот подключается к SharePoint и получает задачи из очереди «ICS-60001 Document review»; каждая задача парсится в DocumentReviewResult (sampleDoc + userInput);
  2. Бот строит map byDoc: documentNumber → UserInput (status, comment, uploadedFileGuid, uploadedFileName); считает checkedDocsCount (результаты с непустым userInput);
  3. Бот заполняет файл-шаблон ICS-60001.xlsx через TemplateResultsWorkbookBuilder.build(...) (листы ZFI_FCRP1, Выборка, Популяция, Справочник; именованные ячейки Rate, Materiality_level, Rate_limit, Date_end, Date_current, All_docs, All_docs_to_check, Docs_to_check, Checked_docs);
  4. Бот загружает итоговый ICS-60001.xlsx в папку work/working SharePoint (OVERWRITE);
  5. Для каждого результата с uploadedFileGuid бот скачивает файл из Storage Orchestrator и загружает его в папку work/other evidence SharePoint;
  6. Бот скачивает из SharePoint исходный <sapTransactionCode>.xlsx (из input data) и screenshots.xlsx (из screenshots);
  7. Бот собирает ZIP-технический архив с именем work.technical.archive.filename: разделы ICS-60001.xlsx, input data/<tcode>.xlsx, screenshots/screenshots.xlsx, other evidence/<file> (с уникализацией имён через ensureUniqueEntryName); загружает ZIP в work/working SharePoint;
  8. Бот очищает temp-файлы;
  9. Бот отправляет sendTaskCompleted с mtName=«Проверка ручных проводок»;
  10. Бот отправляет sendProcessCompleted с контекстом controlStatus (расхождения обнаружены, если хотя бы один статус «NOT OK», иначе не обнаружены) и controlResultsLink (полный путь к папке work/working в SharePoint).
Альтернативные пути Ошибка скачивания/загрузки отдельных файлов логируется как warning и не прерывает шаг. При общем исключении бот выбрасывает BusinessException («Finalize and publish results failed»).
Выходные данные
  • SharePoint: ICS-60001.xlsx и ZIP-архив в папке work/working
  • SharePoint: доказательства в папке work/other evidence
  • Email task_completed «Проверка ручных проводок»
  • Email process_completed с controlStatus и controlResultsLink
Дополнительные требования Файл-шаблон ICS-60001.xlsx должен быть доступен процессу; ресурсы Storage Orchestrator доступны для скачивания по guid.
