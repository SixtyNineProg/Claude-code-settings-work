Описание процесса

Назначение бизнес-процесса
Автоматизация контроля корректности ручных бухгалтерских проводок: получение данных из SAP, расчёт порога существенности, формирование унифицированной структуры папок в SharePoint, подготовка и редактирование справочника типов документов, формирование случайной выборки, обогащение владельцами из MIM, рассылка заданий, проверка документов через web-интерфейсы и публикация итогового отчёта с техническим архивом.

Упрощенная BPMN схема бизнес-процесса

Файл-исходник: ICS-60001.bpmn

Выходные данные бизнес-процесса
Итоговый отчёт ICS-60001.xlsx на основе шаблона (листы ZFI_FCRP1, Выборка, Популяция, Справочник), технический архив ZIP (результаты + input data + screenshots + other evidence), загруженные доказательства в папку «other evidence», email-уведомления пользователям и контролёру, сформированные папки SharePoint по унифицированной структуре UnifiedFoldersUtil.monthly(processName, reportEndDate).

Сценарий использования (перечень Steps)

ICS-60001-Step-01 Инициализация параметров, расчёт порога существенности и создание структуры папок в SharePoint
ICS-60001-Step-02 Получение данных отчёта из SAP (SAP GUI или mock-режим) и парсинг позиций документов
ICS-60001-Step-03 Подготовка списков типов документов (allowed/denied/unclassified) и постановка задания в очередь редактора
ICS-60001-Step-04 Редактирование списков типов документов (web-интерфейс document-type-policy-editor)
ICS-60001-Step-05 Сохранение утверждённых списков типов документов в ресурсы Orchestrator
ICS-60001-Step-06 Подготовка случайной выборки документов для проверки
ICS-60001-Step-07 Обогащение выборки владельцами и контролёром через MIM
ICS-60001-Step-08 Рассылка заданий исполнителям и контролёру, создание задач documentReview
ICS-60001-Step-09 Обработка документа пользователем (web-интерфейс document-review)
ICS-60001-Step-10 Финализация и публикация результатов: итоговый отчёт, технический архив, уведомления

Возможные исключения (Exceptions)

№ Описание Тип исключения Действие Bot при наступлении
ICS-60001-EX-01 Ошибка интеграции с SAP/SharePoint/MIM, отсутствие обязательных данных в транзакции, ошибка создания папок, ошибка парсинга Excel, ошибка постановки/чтения задач Orchestrator, некорректный reportEndDate, отсутствие ресурса sap_settings Системное/Бизнес
  1. Шаг выбрасывает BusinessException/IllegalStateException с контекстом ошибки;
  2. Инфраструктура Orchestrator фиксирует ошибку запуска; стандартные шаблоны process_error в коде явно не вызываются — обработка делегирована инфраструктуре;
  3. Процесс завершается с ошибочным статусом.

Хранилище

Файловое хранилище Orchestrator (Storage) и SharePoint. Структура папок в SharePoint формируется через UnifiedFoldersUtil.monthly(processName, resolvedReportEndDate) и содержит подпапки: work/screenshots, work/input data, work/working, work/other evidence; имя технического архива формируется методом getTechnicalArchiveFilename().

№ п/п Наименование папки в SharePoint (относительно sharepointBasePath) Описание Ключ в ProcessTransaction
1 work/screenshots Скриншоты SAP-транзакции (workbook screenshots.xlsx) work.screenshots.folder.path
2 work/input data Исходный Excel-отчёт SAP (ZFI_FCRP1.xlsx) work.input.data.folder.path
3 work/working Рабочая папка: итоговый ICS-60001.xlsx и технический архив ZIP work.working.folder.path
4 work/other evidence Загруженные пользователями подтверждающие документы work.other.evidence.folder.path
