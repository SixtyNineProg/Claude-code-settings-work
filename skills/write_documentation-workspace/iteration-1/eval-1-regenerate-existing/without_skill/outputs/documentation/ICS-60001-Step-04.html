Идентификатор ICS-60001-Step-04
Определение Редактирование списков типов документов (web-интерфейс document-type-policy-editor)
Класс Java / артефакт Web-действие document-type-policy-editor.js (ресурс src/main/resources/actions/document-type-policy-editor.js); визуализация через Shadow Core Engine
Пользователь Исполнитель (контролёр справочника)
Входные данные
  • Задача из очереди «ICS-60001 Document type policy editor» с тегом pendingPolicyUpdate
  • Параметр задачи initialData = {allowedDocList, deniedDocList} (массивы одноэлементных мап {code: comment})
  • Ссылка на действие documentTypePolicyEditorActionLink
Основной путь
  1. Исполнитель открывает web-интерфейс «Редактор списков типов документов»;
  2. Таблица отображает вид документа, комментарий и признак «Включены» (allowed/denied);
  3. Исполнитель редактирует комментарии, включает/отключает типы документов для проверки;
  4. При нажатии «Сохранить» форма преобразует массив объектов обратно в массив одноэлементных мап и отправляет обновлённый initialData в задачу, меняя тег на policyUpdated;
  5. Исполнитель подтверждает список для дальнейшей работы.
Альтернативные пути Ошибка сохранения изменений — Исполнитель получает уведомление, повторяет попытку или обращается в support. Если форма отправила [object Object] вместо JSON — шаг 5 выбросит BusinessException с диагностическим сообщением.
Выходные данные
  • Обновлённая задача в очереди «ICS-60001 Document type policy editor» с тегом policyUpdated и обновлённым initialData
  • Обновлённые allowed/denied списки и комментарии
Дополнительные требования Возможность массового редактирования; корректная сериализация JSON в браузере (без [object Object]).
