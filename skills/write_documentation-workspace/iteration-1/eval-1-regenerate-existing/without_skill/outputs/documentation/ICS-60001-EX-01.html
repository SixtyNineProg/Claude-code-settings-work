Идентификатор ICS-60001-EX-01
Определение Системная/бизнес-ошибка шага процесса: ошибка интеграции (SAP, SharePoint, MIM, CurrencyRates), отсутствие обязательных данных в транзакции, некорректные параметры инициализации, ошибка парсинга Excel, ошибка web-формы ([object Object]), отсутствие ресурса sap_settings, отсутствие системного свойства transaction.path
Тип исключения Системное / Бизнес
Источники в коде
  • BusinessException в шагах 1, 2, 5, 6, 7, 8, 10
  • IllegalStateException при отсутствии InitParameters, обязательных ключей транзакции, transaction.path
  • IllegalArgumentException при некорректном reportEndDate
  • SessionException при сбое SAP GUI (шаг 2)
Действие Bot при наступлении
  1. Шаг логирует ошибку с контекстом и выбрасывает соответствующее исключение;
  2. Стандартный шаблон process_error в коде явно не вызывается — обработка делегирована инфраструктуре Orchestrator;
  3. Процесс завершается с ошибочным статусом; задача попадает в обработку support-группы.
Действие Исполнителя при наступлении
  • Получить уведомление об ошибке от инфраструктуры;
  • Ожидать информации от support-группы по решению проблемы или скоординировать действия самостоятельно.
