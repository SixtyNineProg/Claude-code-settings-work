Идентификатор ICS-60001-Step-06
Определение Подготовка случайной выборки документов для проверки
Класс Java by.a1.ics60001.steps.SamplePreparationStep
Пользователь Bot
Входные данные
  • Transaction: accounting.document.positions, doc.types.white.list
  • Резервно: ресурс document_type_classification (если doc.types.white.list пуст)
Основной путь
  1. Бот загружает allowedDocTypes из doc.types.white.list (или из document_type_classification);
  2. Бот группирует позиции по documentNumber (LinkedHashMap, сохраняя порядок) в AccountingDocumentGroup (заголовок группы берётся из первой позиции);
  3. Бот фильтрует группы по совпадению documentType с allowed-множеством;
  4. Бот считает размер выборки:
    • total ≤ 0 → 0;
    • total ≤ 12 → min(2, total);
    • total ≤ 52 → 5;
    • total ≤ 365 → 15;
    • иначе → 25.
  5. Бот перемешивает индексы (Collections.shuffle), берёт первые sampleSize, сортирует выборку по первому вхождению документа в исходный список позиций;
  6. Бот собирает уникальные username из выборки как owners;
  7. Бот сохраняет в транзакцию sample.documents, sample.owners, documents.filtered.
Альтернативные пути При любом исключении бот выбрасывает BusinessException («Sample preparation failed»).
Выходные данные
  • Transaction: sample.documents (List<AccountingDocumentGroup>), sample.owners (List<String>), documents.filtered (List<AccountingDocumentGroup>)
Дополнительные требования —
Возможные исключения ICS-60001-EX-01
