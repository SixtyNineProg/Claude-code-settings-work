Общее описание

Процесс «ICS-60001 / Контроль корректности ручных бухгалтерских проводок» автоматизирует контроль ручных бухгалтерских проводок: инициализирует параметры, получает данные из SAP (через SAP GUI или mock-режим), рассчитывает порог существенности на основе курса валюты, формирует унифицированную структуру папок в SharePoint, готовит и редактирует справочники типов документов, формирует выборку документов, обогащает её владельцами из MIM, рассылает задания исполнителям и контролёру, организует проверку документов через web-интерфейсы и публикует итоговый отчёт с техническим архивом в SharePoint.

Реализация: Java-модуль rpa-suite/ics60001 (group by.a1.ics60001, версия 1.0.0), запускается через by.a1.rpa.core.StepRunnerMain; шаги реализуют интерфейс by.a1.rpa.core.Step и связаны через ProcessTransaction (хранилище ключ-значение в рамках транзакции Orchestrator).

Документация по процессу состоит из следующих разделов:

  • ICS-60001: История изменений
  • ICS-60001: Инструкция по развертыванию
  • ICS-60001-PDD: Process Design Document / Документ проектирования процесса
  • ICS-60001-TD: Test Documentation / Тестовая документация
  • ICS-60001-UG: User Guide / Руководство пользователя
