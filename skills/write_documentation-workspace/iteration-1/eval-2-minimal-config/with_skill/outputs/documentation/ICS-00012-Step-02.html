Идентификатор ICS-00012-Step-02
Определение Script Executing
Пользователь Bot
Входные данные
  • init_params: serverName, fileDirectory, countLimit, scriptBlock
  • credential: svc_wf_rm_credentials (login/password для WinRM)
Основной путь
  1. Бот получает credentials svc_wf_rm_credentials из Orchestrator;
  2. Бот формирует тело скрипта, подставляя fileDirectory в scriptBlock вместо %{directory};
  3. Бот запускает PowerShell (Invoke-Command на serverName) и получает количество файлов;
  4. Бот сравнивает count с countLimit;
  5. Если count ≥ countLimit — Бот сохраняет isTicketNeeded=true, scriptResult (count) и текущие дату/время в транзакцию;
  6. Если count < countLimit — Бот сохраняет isTicketNeeded=false.
Альтернативные пути Если PowerShell-скрипт завершился с ошибкой или вернул некорректный ответ, Бот выбрасывает BusinessException и процесс останавливается.
Выходные данные
  • isTicketNeeded (boolean) — признак необходимости создания тикета
  • scriptResult (Integer) — количество файлов
  • dateTime (String) — дата/время проверки (Europe/Minsk)
Дополнительные требования Учётная запись svc_wf_rm_credentials должна иметь права на удалённый запуск PowerShell (Invoke-Command) на serverName.
Возможные исключения ICS-00012-EX-01, ICS-00012-EX-02
