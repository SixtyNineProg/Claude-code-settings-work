Описание шагов процесса с точки зрения действий Исполнителя

Шаг (со ссылкой на PDD) Наименование Действия Исполнителя Действия Bot
ICS-00012-Step-01 Start Notification
  • Получает уведомление о начале работы процесса.
  • Бот загружает конфигурационные параметры (emailRecipients);
  • Бот отправляет уведомление о старте процесса на адреса to/cc.
ICS-00012-Step-02 Script Executing Исполнитель не участвует (процесс выполняется автоматически)
  • Бот получает credentials svc_wf_rm_credentials;
  • Бот формирует тело PowerShell-скрипта, подставляя fileDirectory в scriptBlock;
  • Бот запускает скрипт на удалённом сервере и получает количество файлов;
  • Бот сравнивает count с countLimit и сохраняет признак необходимости тикета, число файлов и дату/время.
ICS-00012-Step-03 Jira Ticket Creation Исполнитель не участвует (процесс выполняется автоматически)
  • Бот получает credentials jira_jsd_credentials;
  • Бот формирует заголовок и описание задачи из шаблонов init_params;
  • Бот создаёт задачу в Jira и назначает исполнителя issueAssignee;
  • Бот сохраняет ticketId в транзакцию.
ICS-00012-Step-04 End Notification
  • Получает письмо с результатами работы Бота (со ссылкой на тикет Jira при наличии).
  • Бот формирует письмо-отчёт о завершении (process_completed);
  • При наличии ticketId добавляет ссылку https://{jiraUrl}/browse/{ticketId} в параметр controlResultsLink;
  • Бот отправляет Исполнителю письмо через электронную почту.

Работа Исполнителя с исключениями

№ Описание Тип исключения Действие Исполнителя при наступлении
ICS-00012-EX-01 Ошибка выполнения PowerShell-скрипта на удалённом сервере Системное
  • Получить уведомление об ошибке: "Ботопроцесс ICS-00012. Во время выполнения ботопроцесса возникла ошибка. Ботопроцесс остановлен."
  • Проверить доступность сервера srv-roamtrns-03 и права учётной записи svc_wf_rm_credentials;
  • Ожидать информации от support группы по решению проблемы либо скоординировать действия самостоятельно.
ICS-00012-EX-02 Пустой или некорректный формат ответа скрипта Системное
  • Получить уведомление об ошибке;
  • Проверить корректность scriptBlock и доступность каталога fileDirectory на сервере;
  • Ожидать информации от support группы либо скоординировать действия самостоятельно.
ICS-00012-EX-03 Не удалось создать тикет в Jira (получен пустой issue id) Системное
  • Получить уведомление об ошибке;
  • Проверить права учётной записи jira_jsd_credentials в проекте SOX и корректность issueProject/issueType;
  • Ожидать информации от support группы либо скоординировать действия самостоятельно.
