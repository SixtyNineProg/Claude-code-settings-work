Идентификатор ICS-00012-Step-04
Определение End Notification
Пользователь Bot
Входные данные
  • init_params: emailRecipients, jiraUrl
  • из транзакции: ticketId (может быть null, если тикет не создавался)
Основной путь
  1. Бот загружает emailRecipients из конфигурации;
  2. Если ticketId не null — Бот формирует ссылку https://{jiraUrl}/browse/{ticketId} и отправляет уведомление о завершении (process_completed) с параметром controlResultsLink;
  3. Если ticketId null — Бот отправляет стандартное уведомление о завершении (process_completed) без ссылки;
  4. Бот завершает работу.
Альтернативные пути —
Выходные данные
  • письмо с результатами работы Бота (со ссылкой на тикет Jira при наличии)
Дополнительные требования —
Возможные исключения ICS-00012-EX-01

Приложения

Пример письма с результатом работы
картинка с письмом, где видны тема и тело (стандартный шаблон process_completed со ссылкой на тикет Jira)
