Идентификатор ICS-00057-Step-08
Определение SaveAllStep — Обработка результатов MT №3
Пользователь Bot
Входные данные
  • InitParameters (emailRecipients)
  • checklistAccounts, mtComments — из транзакции
  • задача MT №3 из очереди (тег reviewedAll, статус IN_PROGRESS)
Основной путь
  1. Бот ищет в очереди MT №3 задачу с именем processAll, тегом reviewedAll и статусом IN_PROGRESS;
  2. Бот разбирает initialData задачи в ProcessAllResult и извлекает processedAccounts (может быть пустым, если контролёр не внёс правок);
  3. Бот обновляет checklistAccounts обработанными счетами (AccountChecklistHelper.updateWith);
  4. Бот объединяет комментарии processedAccounts с mtComments;
  5. Бот сохраняет обновлённые checklistAccounts и mtComments в транзакцию;
  6. Бот отправляет письмо task_processed;
  7. Бот переводит задачу в SUCCESS и заменяет все теги на processedAll.
Альтернативные пути 2. MT №3 безусловна — шаг не ветвится по workflow_status и всегда разбирает processedAccounts (возможно пустой список). После финализации задачи бот запускает UploadEvidenceStep.
Выходные данные
  • обновлённые checklistAccounts, mtComments — в ProcessTransaction
  • финализированная задача MT №3 (SUCCESS, тег processedAll)
Дополнительные требования Шаг запускается Orchestrator-триггером по тегу reviewedAll в очереди «ICS-00057 Обновление справочника»
Возможные исключения ICS-00057-EX-05, ICS-00057-EX-06, ICS-00057-EX-07
