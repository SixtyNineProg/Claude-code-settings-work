Идентификатор ICS-00057-Step-06
Определение SaveChangedStep — Обработка результатов MT №2
Пользователь Bot
Входные данные
  • InitParameters (emailRecipients)
  • workflow_status — из транзакции
  • checklistAccounts, mtComments — из транзакции
  • задача MT №2 из очереди (тег reviewedChanged, статус IN_PROGRESS)
Основной путь
  1. Бот ищет в очереди MT №2 задачу с именем processChanged, тегом reviewedChanged и статусом IN_PROGRESS;
  2. Если workflow_status="changed_accounts_exist" — Бот разбирает initialData задачи в ProcessChangedResult и извлекает processedAccounts;
  3. Бот обновляет checklistAccounts обработанными счетами (AccountChecklistHelper.updateWith);
  4. Бот объединяет комментарии processedAccounts с mtComments;
  5. Бот сохраняет обновлённые checklistAccounts и mtComments в транзакцию;
  6. Бот отправляет письмо task_processed;
  7. Бот переводит задачу в SUCCESS и заменяет все теги на processedChanged.
Альтернативные пути 2. Если workflow_status="no_changed_accounts" (auto-trigger путь) или неизвестный — Бот пропускает разбор processedAccounts, но ОБЯЗАТЕЛЬНО финализирует задачу (SUCCESS + processedChanged), чтобы снять её с триггера и предотвратить повторный запуск Stage3.
Выходные данные
  • обновлённые checklistAccounts, mtComments — в ProcessTransaction
  • финализированная задача MT №2 (SUCCESS, тег processedChanged)
Дополнительные требования Шаг запускается Orchestrator-триггером по тегу reviewedChanged в очереди «ICS-00057 Обновление справочника»
Возможные исключения ICS-00057-EX-05, ICS-00057-EX-06, ICS-00057-EX-07
