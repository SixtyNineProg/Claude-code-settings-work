1

Проверить, что все элементы процесса соответствуют принятому стилю
2

Подготовить необходимые файлы и выполнить перенос процесса на прод согласно общей инструкции
3

Проверяем/Создаем Ресурсы типа Credential на целевой среде (без них процесс не сможет авторизоваться в системах):

  • sap_credentials
  • sharepoint_credentials
  • sherpa_api_credentials
  • smtp_credentials
4

Проверяем/Создаем Ресурсы типа Text на целевой среде:

  • sap_settings
  • ics00057_accounts_init_params
  • ics00057_accounts_email_templates
5

Проверяем/Создаем папку в Хранилище Orchestrator Storage с именем из параметра storageFolderName (по умолчанию ICS-00057) — туда бот загружает выгрузку SAP, скриншоты, чек-лист и технический архив под плоскими именами с суффиксом даты-времени. Также процесс использует два файла-состояния в Storage: ics00057_accounts.json (справочник счетов) и ics00057_comments.json (комментарии MT).
6

Проверяем/Создаем Очередь задач ICS-00057 Обновление справочника — общая очередь для трёх Manual Task (MT №1 «Проверка новых счетов», MT №2 «Проверка изменения меток счетов», MT №3 «Внесение изменений по счетам»). Теги MT не конфликтуют: pending / reviewed / processed (MT №1), pendingChanged / reviewedChanged / processedChanged (MT №2), pendingAll / reviewedAll / processedAll (MT №3).
7

Проверяем/Создаем Триггеры типа Task Queue в Orchestrator для очереди ICS-00057 Обновление справочника: по тегу reviewed запуск SaveNewStep (Stage2), по тегу reviewedChanged запуск SaveChangedStep (Stage3), по тегу reviewedAll запуск SaveAllStep (Stage4). При срабатывании триггера статус задачи переводится в In Progress.

Дополнительные действия (дополнения к указанному в таблице/прочая информация, которую удобнее расположить так):

  1. Загрузить в файловое хранилище скрипты форм Manual Task: actions/process_new.js, actions/process_changed.js, actions/process_all.js (общие core.js и style.css берутся из rpa-core/src/test/resources/manualtask/);
  2. Создать три Action в Orchestrator (по одному на MT) и прописать их ссылки в параметрах processNewActionLink, processChangedActionLink, processAllActionLink InitParams соответствующей среды;
  3. Убедиться, что учётные записи SAP, SharePoint и Sherpa API заведены в Интеграции со сторонними системами;
  4. Ассет sap_settings должен содержать language = "RU" — имена счетов зависят от языка SAP.
