Идентификатор ICS-00057-Step-07
Определение PrepareAllStep — Подготовка MT №3
Пользователь Bot
Входные данные
  • checklistAccounts, mtComments — из транзакции
  • InitParameters (emailRecipients, processAllActionLink)
Основной путь
  1. Бот читает полный справочник checklistAccounts и комментарии mtComments из транзакции;
  2. Бот читает sherpa_api_credentials;
  3. Бот формирует initialData (allAccounts для autocomplete, comments, bearerToken) и создаёт задачу MT №3 (processAll) с тегом pendingAll и processStage=4;
  4. Бот отправляет письмо new_tasks со ссылкой processAllActionLink.
Альтернативные пути — Задача MT №3 безусловна (контролёр сам определяет счета для корректировки, добавляя строки в форму), поэтому auto-trigger ветка «нет новых задач» отсутствует.
Выходные данные
  • задача MT №3 в очереди Orchestrator (тег pendingAll, processStage=4)
Дополнительные требования Системное свойство transaction.path должно быть задано
Возможные исключения ICS-00057-EX-07
