Идентификатор ICS-00057-Step-02
Определение SapStep — Выгрузка справочника счетов из SAP
Пользователь Bot
Входные данные
  • InitParameters (mockSap, unloadingFileName, screenshotsFileName, storageFolderName, spVactproBase, spVactproProject, spVactproPath)
  • ReportingPeriod из транзакции
Основной путь
  1. Бот получает credentials SharePoint (sharepoint_credentials) и создаёт унифицированную структуру папок периода в SharePoint (FolderStructure.from(reportingPeriod)), удаляя папку прочих доказательств;
  2. Бот создаёт локальную временную папку;
  3. Если mockSap=true — Бот копирует выгрузку и скриншоты из ресурсов sap_mock/*;
  4. Если mockSap=false — Бот завершает процессы saplogon.exe/saplgpad.exe, читает sap_credentials и sap_settings, подключается к SAP через SapGuiAutomation;
  5. Бот запускает транзакцию ZACCOUNTS, заполняет план счетов IFRS и БЕ 1320, делает скриншот параметров;
  6. Бот нажимает F8 (выполнение отчёта), ждёт появления кнопки экспорта, делает скриншот первой страницы;
  7. Бот эмулирует Ctrl+PageDown (Robot) для прокрутки к последней странице и делает скриншот;
  8. Бот инициирует экспорт ALV в Excel (Ctrl+Shift+F10 → Ctrl+Shift+F7), указывает путь и имя файла, сохраняет выгрузку;
  9. Бот завершает EXCEL.EXE и закрывает SAP-сессию;
  10. Бот сохраняет скриншоты в xlsx через ExcelScreenshotHelper и парсит выгрузку в List<Account> через ExcelSapUnloadingParser;
  11. Бот загружает выгрузку и скриншоты в Orchestrator Storage (папка storageFolderName) под плоским именем с суффиксом даты-времени;
  12. Бот сохраняет в транзакцию sapAccounts, sapScreenshotsStorageName, sapUnloadingStorageName;
  13. Бот удаляет временную папку.
Альтернативные пути 3. В mock-режиме шаг не обращается к SAP — выгрузка берётся из ресурсов (для тестирования частей процесса, не связанных с SAP).
Выходные данные
  • sapAccounts — список счетов из SAP
  • sapScreenshotsStorageName — плоское имя файла скриншотов в Storage
  • sapUnloadingStorageName — плоское имя файла выгрузки в Storage
Дополнительные требования Ассет sap_settings должен содержать language = "RU" (имена счетов зависят от языка); план счетов IFRS, БЕ 1320
Возможные исключения ICS-00057-EX-02, ICS-00057-EX-03, ICS-00057-EX-07
