Идентификатор ICS-00057-Step-05
Определение PrepareChangedStep — Подготовка изменённых счетов для MT №2
Пользователь Bot
Входные данные
  • sapAccounts, checklistAccounts, mtComments — из транзакции
  • InitParameters (emailRecipients, processChangedActionLink)
Основной путь
  1. Бот вычисляет существующие счета (AccountChecklistHelper.getExistingAccounts) относительно SAP-выгрузки;
  2. Бот определяет счета с изменёнными метками (getAccountsWithChangedMarks) и разбивает их на «с метками» (неизменяемые) и «без меток» (редактируемые);
  3. Бот сохраняет в транзакцию changedAccountsWithMarks, changedAccountsWithoutMarks (как AccountUpdated);
  4. Если изменения есть — Бот читает sherpa_api_credentials, формирует initialData (changedAccounts, changedAccountsImmutable, comments, bearerToken) и создаёт задачу MT №2 (processChanged) с тегом pendingChanged и processStage=3;
  5. Бот отправляет письмо new_tasks со ссылкой processChangedActionLink;
  6. Бот устанавливает workflow_status="changed_accounts_exist".
Альтернативные пути 4. Если счетов с изменёнными метками нет — Бот отправляет письмо no_new_tasks, устанавливает workflow_status="no_changed_accounts" и программно создаёт auto-trigger задачу MT №2 (pendingChanged → IN_PROGRESS + reviewedChanged), по которой Orchestrator-триггер запустит Stage3 без ручной проверки.
Выходные данные
  • changedAccountsWithMarks, changedAccountsWithoutMarks — в ProcessTransaction
  • workflow_status — в ProcessTransaction
  • задача MT №2 в очереди Orchestrator (тег pendingChanged или auto-trigger reviewedChanged)
Дополнительные требования Системное свойство transaction.path должно быть задано
Возможные исключения ICS-00057-EX-07
