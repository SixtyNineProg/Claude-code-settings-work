Идентификатор ICS-00057-Step-03
Определение PrepareNewStep — Подготовка новых счетов для MT №1
Пользователь Bot
Входные данные
  • sapAccounts — из транзакции
  • InitParameters (emailRecipients, processNewActionLink)
Основной путь
  1. Бот читает справочник счетов (ProcessStateService.selectAccounts из ics00057_accounts.json) и комментарии (selectComments из ics00057_comments.json);
  2. Бот вычисляет новые счета (AccountChecklistHelper.getNewAccounts) относительно SAP-выгрузки;
  3. Бот разбивает новые счета на «с метками» (неизменяемые) и «без меток» (редактируемые);
  4. Бот сохраняет в транзакцию newAccountsWithMarks, newAccountsWithoutMarks, checklistAccounts, mtComments;
  5. Если новые счета есть — Бот читает sherpa_api_credentials, формирует initialData (счета «без меток»/«с метками», комментарии, bearerToken) и создаёт задачу MT №1 (processNew) в очереди «ICS-00057 Обновление справочника» с тегом pending и processStage=2;
  6. Бот отправляет письмо new_tasks со ссылкой processNewActionLink;
  7. Бот устанавливает workflow_status="new_accounts_exist".
Альтернативные пути 5. Если новых счетов нет — Бот отправляет письмо no_new_tasks, устанавливает workflow_status="no_new_accounts" и программно создаёт auto-trigger задачу MT №1 (create-then-update: pending → IN_PROGRESS + тег reviewed), по которой Orchestrator-триггер запустит Stage2 без ручной проверки.
Выходные данные
  • newAccountsWithMarks, newAccountsWithoutMarks — в ProcessTransaction
  • checklistAccounts, mtComments — в ProcessTransaction
  • workflow_status — в ProcessTransaction
  • задача MT №1 в очереди Orchestrator (тег pending или auto-trigger reviewed)
Дополнительные требования Системное свойство transaction.path должно быть задано (используется для transactionName в параметрах MT)
Возможные исключения ICS-00057-EX-04, ICS-00057-EX-07
