Идентификатор ICS-00057-Step-04
Определение SaveNewStep — Обработка результатов MT №1
Пользователь Bot
Входные данные
  • InitParameters (emailRecipients)
  • workflow_status — из транзакции
  • checklistAccounts, mtComments — из транзакции
  • задача MT №1 из очереди (тег reviewed, статус IN_PROGRESS)
Основной путь
  1. Бот ищет в очереди MT №1 задачу с именем processNew, тегом reviewed и статусом IN_PROGRESS;
  2. Если workflow_status="new_accounts_exist" — Бот разбирает initialData задачи в ProcessNewResult и извлекает processedAccounts;
  3. Бот обновляет checklistAccounts новыми обработанными счетами (AccountChecklistHelper.updateWith);
  4. Бот объединяет комментарии processedAccounts с mtComments;
  5. Бот сохраняет обновлённые checklistAccounts, mtComments, newProcessedAccounts в транзакцию;
  6. Бот отправляет письмо task_processed;
  7. Бот переводит задачу в SUCCESS и заменяет все теги на processed.
Альтернативные пути 2. Если workflow_status="no_new_accounts" (auto-trigger путь) или неизвестный — Бот пропускает разбор processedAccounts, но ОБЯЗАТЕЛЬНО финализирует задачу (SUCCESS + processed), чтобы снять её с триггера и предотвратить повторный запуск Stage2.
Выходные данные
  • обновлённые checklistAccounts, mtComments — в ProcessTransaction
  • newProcessedAccounts — в ProcessTransaction
  • финализированная задача MT №1 (SUCCESS, тег processed)
Дополнительные требования Шаг запускается Orchestrator-триггером по тегу reviewed в очереди «ICS-00057 Обновление справочника»
Возможные исключения ICS-00057-EX-05, ICS-00057-EX-06, ICS-00057-EX-07
