Описание процесса

Назначение бизнес-процесса
Первый шаг контроля ICS-00057: обновление справочника релевантных для контроля счетов. Бот выгружает справочник счетов из SAP (ZACCOUNTS), сравнивает с состоянием в Orchestrator Assets, формирует три последовательные Manual Task для контролёра (новые счета, изменённые метки, корректировки) и загружает итоговые доказательства (чек-лист и технический архив) в SharePoint и Orchestrator Storage по унифицированной структуре папок.

Упрощенная BPMN схема бизнес-процесса

Файл-исходник: ICS-00057.bpm

Выходные данные бизнес-процесса
Письмо с информацией о завершении работы и ссылкой на папку SharePoint с результатами; обновлённые ассеты состояния справочника и комментариев в Orchestrator Storage; чек-лист и технический ZIP-архив в Storage и SharePoint

Сценарий использования (перечень Steps)

ICS-00057-Step-01 InfrastructureStep — Подготовка инфраструктуры
ICS-00057-Step-02 SapStep — Выгрузка справочника счетов из SAP
ICS-00057-Step-03 PrepareNewStep — Подготовка новых счетов для MT №1
ICS-00057-Step-04 SaveNewStep — Обработка результатов MT №1
ICS-00057-Step-05 PrepareChangedStep — Подготовка изменённых счетов для MT №2
ICS-00057-Step-06 SaveChangedStep — Обработка результатов MT №2
ICS-00057-Step-07 PrepareAllStep — Подготовка MT №3
ICS-00057-Step-08 SaveAllStep — Обработка результатов MT №3
ICS-00057-Step-09 UploadEvidenceStep — Загрузка результатов на SharePoint и в Storage

Возможные исключения (Exceptions)

№ Описание Тип исключения Действие Bot при наступлении
ICS-00057-EX-01 Некорректный отчётный период: periodStart >= periodEnd или periodEnd >= дата запуска (параметры парсятся, но не проходят валидацию) Бизнес
  1. Бот выбрасывает BusinessException с описанием периода и даты запуска;
  2. rpa-core HandleErrorStep отправляет письмо process_error Исполнителю и support-группе;
  3. Процесс останавливается с ошибочным статусом.
ICS-00057-EX-02 Ошибка SAP-сессии: сбой подключения к SAP Logon, транзакция ZACCOUNTS не выполнена, экспорт в Excel не построен Системное
  1. Бот логирует ошибку SessionException;
  2. Бот выбрасывает BusinessException("SAP session failed");
  3. HandleErrorStep отправляет process_error;
  4. Процесс останавливается.
ICS-00057-EX-03 Прочий сбой шага SapStep (ошибка Robot при эмуляции клавиатуры/мыши, недоступен ресурсный файл mock-режима, ошибка выгрузки) Системное
  1. Бот логирует причину;
  2. Бот выбрасывает BusinessException("SAP step failed" / "Cannot perform mocked SAP transaction" / "Resource file not found");
  3. HandleErrorStep отправляет process_error;
  4. Процесс останавливается.
ICS-00057-EX-04 Ошибка чтения/записи состояния справочника или комментариев (файлы ics00057_accounts.json / ics00057_comments.json в Storage) Системное
  1. Бот логирует ошибку работы с Storage;
  2. Бот выбрасывает BusinessException("Failed to read/write storage file: ...");
  3. HandleErrorStep отправляет process_error;
  4. Процесс останавливается.
ICS-00057-EX-05 Ошибка парсинга результата MT-задачи: параметр initialData отсутствует, пуст или имеет необрабатываемый формат Системное
  1. Бот логирует guid задачи и причину;
  2. Бот выбрасывает BusinessException("Failed to parse MT №1/№2/№3 task ...");
  3. HandleErrorStep отправляет process_error;
  4. Процесс останавливается.
ICS-00057-EX-06 Не найдена MT-задача в очереди: отсутствует задача с ожидаемым именем, final-тегом и статусом IN_PROGRESS (сработал триггер, но задача не найдена) Системное
  1. Бот логирует критерий поиска;
  2. Бот выбрасывает IllegalStateException (оборачивается в BusinessException на верхнем уровне SaveNewStep/SaveChangedStep/SaveAllStep);
  3. HandleErrorStep отправляет process_error;
  4. Процесс останавливается.
ICS-00057-EX-07 Отсутствует обязательный параметр транзакции или InitParameters (SAP accounts / Checklist accounts / InitParameters / системное свойство transaction.path) Системное
  1. Бот логирует отсутствующее поле;
  2. Бот выбрасывает IllegalStateException (оборачивается в BusinessException на верхнем уровне шага);
  3. HandleErrorStep отправляет process_error;
  4. Процесс останавливается.

№ Ресурс Группа Описание
