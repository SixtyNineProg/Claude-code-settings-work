Идентификатор ICS-00057-Step-01
Определение InfrastructureStep — Подготовка инфраструктуры
Пользователь Bot
Входные данные
  • InitParameters (emailRecipients, periodStart, periodEnd)
Основной путь
  1. Бот читает InitParameters из транзакции;
  2. Бот отправляет уведомление process_started получателям из emailRecipients;
  3. Бот парсит periodStart/periodEnd в формате dd.MM.yyyy;
  4. Если оба парсятся — Бот валидирует periodStart < periodEnd < today (Europe/Minsk) и формирует ReportingPeriod;
  5. Если хотя бы один не парсится — Бот формирует отчётный период по умолчанию (прошлый квартал от даты запуска);
  6. Бот сохраняет ReportingPeriod (runDate, periodStart, periodEnd) в транзакцию.
Альтернативные пути 4. Если periodStart/periodEnd парсятся, но не проходят валидацию (periodStart >= periodEnd или periodEnd >= today), Бот выбрасывает BusinessException (ICS-00057-EX-01).
Выходные данные
  • ReportingPeriod (runDate, periodStart, periodEnd) — в ProcessTransaction
Дополнительные требования Часовой пояс Europe/Minsk
Возможные исключения ICS-00057-EX-01, ICS-00057-EX-07
