Общее описание

Процесс "ICS-00057" предназначен для обновления справочника релевантных для контроля счетов в рамках первого шага контроля ICS-00057. Процесс выгружает справочник счетов из SAP (транзакция ZACCOUNTS), сравнивает его с актуальным состоянием справочника в Orchestrator Assets, формирует для контролёра три последовательные Manual Task (проверка новых счетов, проверка изменений меток, внесение корректировок) и загружает итоговые доказательства (чек-лист и технический архив) в SharePoint и Orchestrator Storage по унифицированной структуре папок.

С целью трассировки требований общим артефактам по данному процессу присваивается индекс "ICS-00057".

Документация по роботизируемому процессу состоит из следующих разделов:

  • ICS-00057: История изменений
  • ICS-00057: Инструкция по развертыванию
  • ICS-00057-PDD: Process Design Document / Документ проектирования процесса
  • ICS-00057-TD: Test Documentation / Тестовая документация
  • ICS-00057-UG: User Guide / Руководство пользователя
