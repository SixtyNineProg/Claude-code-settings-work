Идентификатор ICS-00012-Step-04
Определение EndNotification
Пользователь Bot
Входные данные
  • init параметры (emailRecipients, jiraUrl)
  • ticketId (String) из Step-03 — опционально, может отсутствовать
Основной путь
  1. Бот загружает emailRecipients из InitParameters;
  2. Бот получает ticketId из транзакции;
  3. Если ticketId не null, Бот формирует ссылку https://{jiraUrl}/browse/{ticketId} и передаёт её как controlResultsLink в sendProcessCompleted;
  4. Иначе Бот отправляет sendProcessCompleted без параметра ссылки;
  5. Бот завершает работу.
Альтернативные пути —
Выходные данные
  • письмо о завершении процесса (со ссылкой на Jira-тикет при наличии)
Дополнительные требования —
Возможные исключения ICS-00012-EX-01
