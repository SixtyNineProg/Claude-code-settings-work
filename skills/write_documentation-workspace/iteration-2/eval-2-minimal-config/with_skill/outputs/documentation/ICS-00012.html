Общее описание

Процесс "ICS-00012" предназначен для мониторинга количества файлов в заданном каталоге на удалённом сервере и автоматического создания тикета в Jira при превышении установленного порога.

С целью трассировки требований общим артефактам по данному процессу присваивается индекс "ICS-00012".

Документация по роботизируемому процессу состоит из следующих разделов:

  • ICS-00012: История изменений
  • ICS-00012: Инструкция по развертыванию
  • ICS-00012-PDD: Process Design Document / Документ проектирования процесса
  • ICS-00012-TD: Test Documentation / Тестовая документация
  • ICS-00012-UG: User Guide / Руководство пользователя
