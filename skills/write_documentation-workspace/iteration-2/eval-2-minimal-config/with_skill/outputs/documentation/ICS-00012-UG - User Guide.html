Краткое описание процесса

Упрощенная BPMN схема бизнес-процесса

Описание шагов процесса с точки зрения действий Исполнителя

Шаг (со ссылкой на PDD) Наименование Действия Исполнителя Действия Bot
ICS-00012-Step-01 StartNotification
  • Получает уведомление о начале работы процесса.
  • Бот уведомляет Исполнителя о начале работы процесса через электронную почту.
ICS-00012-Step-02 ScriptExecuting Исполнитель не участвует (процесс выполняется автоматически)
  • Бот получает учётные данные WinRM и формирует PowerShell-скрипт;
  • Бот запускает скрипт на удалённом сервере и подсчитывает файлы в каталоге;
  • Бот сравнивает количество файлов с порогом и сохраняет признак необходимости тикета.
ICS-00012-Step-03 JiraTicketCreation Исполнитель не участвует (процесс выполняется автоматически)
  • Бот создаёт задачу в Jira с описанием превышения порога файлов;
  • Бот назначает исполнителя задачи и сохраняет ключ тикета в транзакцию.
ICS-00012-Step-04 EndNotification
  • Получает письмо с результатами работы Бота (со ссылкой на Jira-тикет при наличии).
  • Бот формирует письмо-отчёт о завершении процесса;
  • Бот отправляет Исполнителю письмо через электронную почту.

Работа Исполнителя с исключениями

№ Описание Тип исключения Действие Исполнителя при наступлении
ICS-00012-EX-01 Ошибка выполнения PowerShell-скрипта на удалённом сервере Системное
  • Получить уведомление об ошибке: "Ботопроцесс ICS-00012. Во время выполнения ботопроцесса возникла ошибка выполнения скрипта. Ботопроцесс остановлен."
  • Проверить доступность сервера srv-roamtrns-03 и корректность учётных данных svc_wf_rm_credentials;
  • Ожидать информацию от support группы по решению проблемы либо скоординировать действия самостоятельно.
ICS-00012-EX-02 Пустой или некорректный ответ PowerShell-скрипта Системное
  • Получить уведомление об ошибке;
  • Проверить корректность scriptBlock и наличие целевого каталога fileDirectory на сервере;
  • Ожидать информацию от support группы либо скоординировать действия самостоятельно.
ICS-00012-EX-03 Ошибка создания тикета в Jira (пустой идентификатор задачи) Системное
  • Получить уведомление об ошибке;
  • Проверить доступность Jira и корректность учётных данных jira_jsd_credentials;
  • Ожидать информацию от support группы либо скоординировать действия самостоятельно.
