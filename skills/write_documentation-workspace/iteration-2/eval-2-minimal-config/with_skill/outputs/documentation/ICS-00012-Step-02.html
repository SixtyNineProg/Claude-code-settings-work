Идентификатор ICS-00012-Step-02
Определение ScriptExecuting
Пользователь Bot
Входные данные
  • init параметры (serverName, fileDirectory, countLimit, scriptBlock)
Основной путь
  1. Бот получает учётные данные svc_wf_rm_credentials из Orchestrator;
  2. Бот формирует тело PowerShell-скрипта, подставляя fileDirectory в scriptBlock вместо %{directory};
  3. Бот запускает скрипт на сервере serverName через WinRM (PowershellService.exec);
  4. Бот разбирает ответ скрипта и преобразует первую строку в число (count);
  5. Если count >= countLimit, Бот сохраняет в транзакцию isTicketNeeded=true, scriptResult=count и текущие дату/время;
  6. Иначе Бот сохраняет isTicketNeeded=false.
Альтернативные пути При нулевом или ненулевом exitValue процесса powershell.exe Бот выбрасывает BusinessException.
Выходные данные
  • isTicketNeeded (boolean) — флаг необходимости создания тикета
  • scriptResult (Integer) — количество файлов в каталоге
  • dateTime (String) — дата/время проверки в формате EEEE MM/dd/yyyy HH:mm
Дополнительные требования Часовой пояс — Europe/Minsk
Возможные исключения
