Идентификатор ICS-00057-Step-01
Определение InfrastructureStep
Пользователь Bot
Входные данные
  • InitParameters: emailRecipients, periodStart, periodEnd
Основной путь
  1. Бот загружает InitParameters из транзакции;
  2. Бот отправляет уведомление process_started получателям из emailRecipients;
  3. Бот парсит periodStart и periodEnd (формат dd.MM.yyyy);
  4. При успешном парсинге Бот валидирует: periodStart < periodEnd < today (Europe/Minsk);
  5. Бот формирует ReportingPeriod (runDate + границы) и сохраняет его в транзакцию.
Альтернативные пути При непарсимых periodStart/periodEnd («-») Бот рассчитывает отчётный период по умолчанию — прошлый квартал относительно даты запуска (Europe/Minsk).
Выходные данные
  • ReportingPeriod в транзакции (runDate, periodStart, periodEnd);
  • письмо process_started получателям.
Дополнительные требования Часовой пояс расчёта периода — Europe/Minsk.
Возможные исключения ICS-00057-EX-01
