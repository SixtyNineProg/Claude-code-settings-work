1

Проверить, что все элементы процесса соответствуют принятому стилю
2

Подготовить необходимые файлы и выполнить перенос процесса на прод согласно общей инструкции
3

Проверяем/Создаем Ресурсы типа Credential на целевой среде (без них процесс не сможет авторизоваться в системах):

  • sap_credentials — логин и пароль Робота для доступа к серверу SAP
  • sharepoint_credentials — логин и пароль Робота для доступа к каталогам SharePoint
  • sherpa_api_credentials — Bearer-токен для JS-вызовов Manual Task (/api/task/*)
4

Проверяем/Создаем Ресурсы типа Text на целевой среде:

  • sap_settings — JSON SapGuiSettings (путь к SAP Logon, systemName, client, language = "RU")
5

Опционально Проверяем/Создаем папку в Хранилище и загружаем туда нужные файлы. Процесс использует папку Хранилища с именем из параметра storageFolderName (по умолчанию ICS-00057) для выгрузки SAP, скриншотов, чек-листа и технического архива. Файлы хранятся под плоским уникальным именем с суффиксом даты-времени.

Также процесс читает и обновляет файлы состояния в Хранилище: ics00057_accounts.json (справочник счетов) и ics00057_comments.json (комментарии MT).
6

Опционально Проверяем/Создаем Очередь задач с именем ICS-00057 Обновление справочника (общая для MT №1/№2/№3; теги процессов не конфликтуют: pending/reviewed/processed, pendingChanged/reviewedChanged/processedChanged, pendingAll/reviewedAll/processedAll).
7

Опционально Проверяем/Создаем Триггеры Orchestrator (Task Queue, очередь ICS-00057 Обновление справочника):

  • по final-тегу reviewed → статус задачи In Progress → запуск Stage2 (SaveNewStep);
  • по final-тегу reviewedChanged → статус задачи In Progress → запуск Stage3 (SaveChangedStep);
  • по final-тегу reviewedAll → статус задачи In Progress → запуск Stage4 (SaveAllStep → UploadEvidenceStep).

Дополнительные действия (дополнения к указанному в таблице/прочая информация, которую удобнее расположить так):

  1. Загрузить в файловое хранилище скрипты форм Manual Task: actions/process_new.js, actions/process_changed.js, actions/process_all.js (общие core.js и style.css — из rpa-core/src/test/resources/manualtask/);
  2. Прописать в init_params ссылки на загруженные формы (processNewActionLink, processChangedActionLink, processAllActionLink) и параметры отчётного периода (periodStart/periodEnd в формате dd.MM.yyyy, либо - для расчёта прошлого квартала по умолчанию);
  3. Убедиться, что на Бот-машине установлен SAP Logon 750 и настроен Shortcut, описанный в sap_settings (язык RU — имена счетов зависят от языка).
