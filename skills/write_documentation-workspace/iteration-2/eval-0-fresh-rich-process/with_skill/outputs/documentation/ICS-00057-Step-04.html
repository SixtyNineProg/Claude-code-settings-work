Идентификатор ICS-00057-Step-04
Определение SaveNewStep
Пользователь Bot
Входные данные
  • задача MT №1 в очереди с final-тегом reviewed и статусом IN_PROGRESS
  • workflowStatus, checklistAccounts, mtComments из Step-03
Основной путь
  1. Бот-приёмник запускается Orchestrator-триггером по тегу reviewed в очереди MT №1;
  2. Бот находит задачу MT №1 (имя processNew, тег reviewed, статус IN_PROGRESS);
  3. При workflowStatus=new_accounts_exist Бот разбирает initialData → ProcessNewResult → processedAccounts;
  4. Бот обновляет справочник (AccountChecklistHelper.updateWith) и объединяет комментарии;
  5. Бот отправляет письмо task_processed;
  6. Бот переводит задачу в SUCCESS и заменяет все теги на processed (снимает задачу с триггера и предотвращает повторный запуск Stage2).
Альтернативные пути При workflowStatus=no_new_accounts Бот пропускает разбор processedAccounts и сразу финализирует задачу (SUCCESS + тег processed). При неизвестном workflowStatus Бот также безопасно финализирует задачу, предотвращая повторный auto-trigger.
Выходные данные
  • newProcessedAccounts в транзакции;
  • обновлённые checklistAccounts и mtComments;
  • финализированная задача MT №1 (SUCCESS + processed);
  • письмо task_processed (при разобранном результате).
