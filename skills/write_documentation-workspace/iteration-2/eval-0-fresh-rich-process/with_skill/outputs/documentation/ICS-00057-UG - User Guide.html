Описание шагов процесса с точки зрения действий Исполнителя

Шаг (со ссылкой на PDD) Наименование Действия Исполнителя Действия Bot
ICS-00057-Step-01 InfrastructureStep
  • Получает уведомление process_started о начале работы процесса.
  • Загружает InitParameters;
  • Отправляет письмо process_started;
  • Формирует и сохраняет ReportingPeriod (по periodStart/periodEnd или прошлый квартал).
ICS-00057-Step-02 SapStep Исполнитель не участвует (процесс выполняется автоматически)
  • Создаёт структуру папок периода в SharePoint;
  • Подключается к SAP GUI и запускает ZACCOUNTS (IFRS, БЕ 1320, язык RU);
  • Экспортирует ALV в Excel, снимает скриншоты экранов;
  • Загружает выгрузку и скриншоты в Orchestrator Storage (плоское имя).
ICS-00057-Step-03 PrepareNewStep
  • Получает письмо new_tasks со ссылкой на Action-форму MT №1 «Проверка новых счетов»;
  • Открывает форму, проверяет счета «без меток»/«с метками», заполняет комментарии и помечает задачу тегом reviewed.
  • Сравнивает SAP-выгрузку со справочником и определяет новые счета;
  • Создаёт в очереди задачу MT №1 (тег pending, processStage=2);
  • Отправляет письмо new_tasks или no_new_tasks (auto-trigger при отсутствии новых).
ICS-00057-Step-04 SaveNewStep
  • Получает письмо task_processed после разбора результата MT №1.
  • Запускается триггером по тегу reviewed;
  • Разбирает processedAccounts, обновляет справочник и комментарии;
  • Финализирует задачу (SUCCESS + processed), отправляет task_processed.
ICS-00057-Step-05 PrepareChangedStep
  • Получает письмо new_tasks со ссылкой на Action-форму MT №2 «Проверка изменения меток счетов»;
  • Открывает форму, проверяет изменённые счета «без меток»/«с метками», заполняет комментарии и помечает задачу тегом reviewedChanged.
  • Определяет счета с изменёнными метками;
  • Создаёт задачу MT №2 (тег pendingChanged, processStage=3);
  • Отправляет письмо new_tasks или no_new_tasks (auto-trigger при отсутствии изменений).
ICS-00057-Step-06 SaveChangedStep
  • Получает письмо task_processed после разбора результата MT №2.
  • Запускается триггером по тегу reviewedChanged;
  • Разбирает processedAccounts, обновляет справочник и комментарии;
  • Финализирует задачу (SUCCESS + processedChanged), отправляет task_processed.
ICS-00057-Step-07 PrepareAllStep
  • Получает письмо new_tasks со ссылкой на Action-форму MT №3 «Внесение изменений по счетам»;
  • Открывает форму, выбирает счета из справочника (autocomplete) для корректировки, заполняет комментарии и помечает задачу тегом reviewedAll.
  • Читает полный справочник из транзакции;
  • Безусловно создаёт задачу MT №3 (тег pendingAll, processStage=4);
  • Отправляет письмо new_tasks.
ICS-00057-Step-08 SaveAllStep
  • Получает письмо task_processed после разбора результата MT №3.
  • Запускается триггером по тегу reviewedAll;
  • Разбирает processedAccounts (возможно пустой), обновляет справочник и комментарии;
  • Финализирует задачу (SUCCESS + processedAll), отправляет task_processed;
  • Запускает UploadEvidenceStep.
ICS-00057-Step-09 UploadEvidenceStep
  • Получает письмо work_end со ссылкой на папку SharePoint с результатами.
  • Скачивает выгрузку и скриншоты из Хранилища;
  • Формирует чек-лист ICS-00057_01.xlsx и ZIP-архив;
  • Загружает чек-лист и архив в Orchestrator Storage и SharePoint;
  • Обновляет файлы состояния справочника и комментариев;
  • Отправляет письмо work_end со ссылкой на результаты.

Работа Исполнителя с исключениями

№ Описание Тип исключения Действие Исполнителя при наступлении
ICS-00057-EX-01 Некорректный отчётный период (periodStart ≥ periodEnd или periodEnd ≥ дата запуска) Бизнес
  • Получить уведомление process_error: «Во время выполнения ботопроцесса 01 Обновление справочника возникла ошибка.»;
  • Проверить значения periodStart/periodEnd в init_params (формат dd.MM.yyyy, start < end < дата запуска) и при необходимости скорректировать;
  • Ожидать информации от support-группы по решению проблемы либо скоординировать действия самостоятельно.
ICS-00057-EX-02 Ошибка SAP-сессии или экспорта ZACCOUNTS Системное
  • Получить уведомление process_error;
  • Проверить доступность SAP Logon и корректность Shortcut в sap_settings (язык RU);
  • Проверить учётные данные sap_credentials;
  • Ожидать информации от support-группы либо скоординировать действия самостоятельно.
ICS-00057-EX-03 Отсутствует ресурсный файл mock-режима SAP Системное
  • Получить уведомление process_error;
  • Ожидать информации от support-группы по восстановлению ресурсных файлов sap_mock/*.
ICS-00057-EX-04 Ошибка разбора результата формы MT №1 или отсутствует задача с тегом reviewed Системное
  • Получить уведомление process_error;
  • Проверить состояние задачи MT №1 в очереди «ICS-00057 Обновление справочника» и наличие тега reviewed;
  • Ожидать информации от support-группы либо скоординировать действия самостоятельно.
ICS-00057-EX-05 Ошибка разбора результата формы MT №2 или отсутствует задача с тегом reviewedChanged Системное
  • Получить уведомление process_error;
  • Проверить состояние задачи MT №2 в очереди и наличие тега reviewedChanged;
  • Ожидать информации от support-группы либо скоординировать действия самостоятельно.
ICS-00057-EX-06 Ошибка разбора результата формы MT №3 или отсутствует задача с тегом reviewedAll Системное
  • Получить уведомление process_error;
  • Проверить состояние задачи MT №3 в очереди и наличие тега reviewedAll;
  • Ожидать информации от support-группы либо скоординировать действия самостоятельно.
