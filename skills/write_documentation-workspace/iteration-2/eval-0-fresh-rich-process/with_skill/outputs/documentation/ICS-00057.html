Общее описание

Процесс "ICS-00057" предназначен для обновления справочника релевантных для контроля счетов в рамках первого шага контроля ICS-00057 «Обновление справочника»: бот выгружает справочник счетов из SAP (транзакция ZACCOUNTS), сопоставляет его с состоянием в Orchestrator, формирует три Manual Task для ручной проверки контролёром (новые счета, изменение меток, корректировки) и загружает результаты (чек-лист и технический архив) в SharePoint и Orchestrator Storage.

С целью трассировки требований общим артефактам по данному процессу присваивается индекс "ICS-00057".

Документация по роботизируемому процессу состоит из следующих разделов:

  • ICS-00057: История изменений
  • ICS-00057: Инструкция по развертыванию
  • ICS-00057-PDD: Process Design Document / Документ проектирования процесса
  • ICS-00057-TD: Test Documentation / Тестовая документация
  • ICS-00057-UG: User Guide / Руководство пользователя
