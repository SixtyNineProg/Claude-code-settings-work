Идентификатор ICS-00057-Step-08
Определение SaveAllStep
Пользователь Bot
Входные данные
  • задача MT №3 в очереди с final-тегом reviewedAll и статусом IN_PROGRESS
  • checklistAccounts, mtComments из Step-07
Основной путь
  1. Бот-приёмник запускается Orchestrator-триггером по тегу reviewedAll в очереди MT №3;
  2. Бот находит задачу MT №3 (имя processAll, тег reviewedAll, статус IN_PROGRESS);
  3. Бот разбирает initialData → ProcessAllResult → processedAccounts (возможно пустой список);
  4. Бот обновляет справочник (AccountChecklistHelper.updateWith) и объединяет комментарии;
  5. Бот отправляет письмо task_processed;
  6. Бот переводит задачу в SUCCESS и заменяет все теги на processedAll, после чего запускается UploadEvidenceStep.
Альтернативные пути Если контролёр не внёс ни одной правки, processedAccounts пуст — Бот сохраняет справочник без изменений и финализирует задачу.
Выходные данные
  • allProcessedAccounts в транзакции;
  • обновлённые checklistAccounts и mtComments;
  • финализированная задача MT №3 (SUCCESS + processedAll);
  • письмо task_processed.
