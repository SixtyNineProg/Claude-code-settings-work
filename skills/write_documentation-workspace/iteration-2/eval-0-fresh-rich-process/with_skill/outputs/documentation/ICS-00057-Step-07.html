Идентификатор ICS-00057-Step-07
Определение PrepareAllStep
Пользователь Bot
Входные данные
  • checklistAccounts, mtComments из Step-06
  • InitParameters: emailRecipients, processAllActionLink
Основной путь
  1. Бот читает полный справочник из транзакции (checklistAccounts);
  2. Бот создаёт в очереди MT №3 (тег pendingAll, processStage=4) с initialData: весь справочник allAccounts для autocomplete по номеру счета, комментарии и bearerToken;
  3. Бот отправляет письмо new_tasks со ссылкой processAllActionLink.
Альтернативные пути — (MT №3 безусловна: контролёр сам определяет счета для корректировки, добавляя строки в форму; auto-trigger ветка отсутствует.)
Выходные данные
  • задача MT №3 в очереди (тег pendingAll, processStage=4);
  • письмо new_tasks.
Дополнительные требования Системное свойство transaction.path должно быть задано.
