Идентификатор ICS-00057-Step-06
Определение SaveChangedStep
Пользователь Bot
Входные данные
  • задача MT №2 в очереди с final-тегом reviewedChanged и статусом IN_PROGRESS
  • workflowStatus, checklistAccounts, mtComments из Step-05
Основной путь
  1. Бот-приёмник запускается Orchestrator-триггером по тегу reviewedChanged в очереди MT №2;
  2. Бот находит задачу MT №2 (имя processChanged, тег reviewedChanged, статус IN_PROGRESS);
  3. При workflowStatus=changed_accounts_exist Бот разбирает initialData → ProcessChangedResult → processedAccounts;
  4. Бот обновляет справочник (AccountChecklistHelper.updateWith) и объединяет комментарии;
  5. Бот отправляет письмо task_processed;
  6. Бот переводит задачу в SUCCESS и заменяет все теги на processedChanged.
Альтернативные пути При workflowStatus=no_changed_accounts Бот пропускает разбор processedAccounts и сразу финализирует задачу (SUCCESS + тег processedChanged). При неизвестном workflowStatus Бот также безопасно финализирует задачу.
Выходные данные
  • changedProcessedAccounts в транзакции;
  • обновлённые checklistAccounts и mtComments;
  • финализированная задача MT №2 (SUCCESS + processedChanged);
  • письмо task_processed (при разобранном результате).
