Идентификатор ICS-00057-Step-05
Определение PrepareChangedStep
Пользователь Bot
Входные данные
  • sapAccounts из Step-02
  • checklistAccounts, mtComments из Step-04
  • InitParameters: emailRecipients, processChangedActionLink
Основной путь
  1. Бот определяет существующие счета и счета с изменёнными метками (AccountChecklistHelper.getAccountsWithChangedMarks);
  2. Бот разбивает изменённые счета на редактируемые «без меток» и неизменяемые «с метками» и мапит их в AccountUpdated;
  3. Бот создаёт в очереди MT №2 (тег pendingChanged, processStage=3) с initialData: changedAccounts, changedAccountsImmutable, комментарии и bearerToken;
  4. Бот отправляет письмо new_tasks со ссылкой processChangedActionLink.
Альтернативные пути При отсутствии счетов с изменёнными метками Бот создаёт auto-trigger задачу MT №2 (тег pendingChanged → IN_PROGRESS + тег reviewedChanged, processStage=3), отправляет письмо no_new_tasks и сохраняет workflowStatus=no_changed_accounts — триггер запускает Stage3 без ручной проверки.
Выходные данные
  • changedAccountsWithMarks, changedAccountsWithoutMarks в транзакции;
  • workflowStatus (changed_accounts_exist / no_changed_accounts);
  • задача MT №2 в очереди; письмо new_tasks или no_new_tasks.
Дополнительные требования Системное свойство transaction.path должно быть задано.
