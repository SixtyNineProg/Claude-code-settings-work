Идентификатор ICS-00057-Step-03
Определение PrepareNewStep
Пользователь Bot
Входные данные
  • sapAccounts из Step-02
  • InitParameters: emailRecipients, processNewActionLink
  • состояние справочника и комментариев из Хранилища (ProcessStateService)
Основной путь
  1. Бот читает справочник счетов (ics00057_accounts.json) и комментариев (ics00057_comments.json) из Хранилища;
  2. Бот определяет новые счета относительно SAP-выгрузки (AccountChecklistHelper.getNewAccounts) и разбивает их на «с метками» и «без меток»;
  3. Бот создаёт в очереди «ICS-00057 Обновление справочника» задачу MT №1 (тег pending, processStage=2) с initialData: счета «без меток»/«с метками», комментарии и bearerToken из sherpa_api_credentials;
  4. Бот отправляет письмо new_tasks со ссылкой processNewActionLink.
Альтернативные пути При отсутствии новых счетов Бот создаёт auto-trigger задачу MT №1 (тег pending → IN_PROGRESS + тег reviewed, processStage=2), отправляет письмо no_new_tasks и сохраняет workflowStatus= no_new_accounts — Orchestrator-триггер запускает Stage2 без ручной проверки.
Выходные данные
  • newAccountsWithMarks, newAccountsWithoutMarks в транзакции;
  • checklistAccounts, mtComments в транзакции;
  • workflowStatus (new_accounts_exist / no_new_accounts);
  • задача MT №1 в очереди; письмо new_tasks или no_new_tasks.
Дополнительные требования Системное свойство transaction.path должно быть задано (имя файла транзакции используется в параметрах MT-задачи).
