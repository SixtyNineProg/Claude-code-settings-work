Идентификатор ICS-60001-Step-01
Определение Инициализация параметров, расчёт порога существенности и создание структуры папок в SharePoint
Класс Java by.a1.ics60001.steps.ProcessSetupStep
Пользователь Bot
Входные данные
  • Ресурс ics60001_init_params (InitParameters)
  • Ресурс currency_rates_config (CurrencyRatesConfig)
  • Credentials: proxy_credentials, sap_credentials, sharepoint_credentials
  • Системное свойство transaction.path (используется на последующих шагах)
Основной путь
  1. Бот читает InitParameters из транзакции;
  2. Бот вычисляет и сохраняет resolved.report.end.date из reportEndDate:
    • пусто → последний день прошлого месяца;
    • дата yyyy-MM-dd → дата (если в будущем — сегодня);
    • целое число → смещение в месяцах, последний день месяца.
  3. Бот через сервис CurrencyRates получает курс currencyCode на дату resolvedReportEndDate и считает materialityThreshold = rate × materialityLevel; сохраняет ExchangeRate в транзакцию;
  4. Бот создаёт унифицированную структуру папок в SharePoint через UnifiedFoldersUtil.monthly(processName, resolvedReportEndDate) (все пути из getAllPaths()) в sharepointBasePath;
  5. Бот сохраняет в транзакцию пути work.screenshots.folder.path, work.input.data.folder.path, work.working.folder.path, work.other.evidence.folder.path и имя work.technical.archive.filename;
  6. Бот отправляет уведомление sendProcessStarted на emailRecipients.
Альтернативные пути Ошибка загрузки параметров, получения курса валюты или создания папок SharePoint — бот выбрасывает BusinessException («SharePoint folder creation failed») либо IllegalStateException, процесс завершается с ошибкой.
Выходные данные
  • Transaction: exchange.rate, resolved.report.end.date, work.screenshots.folder.path, work.input.data.folder.path, work.working.folder.path, work.other.evidence.folder.path, work.technical.archive.filename
  • Структура папок в SharePoint создана
  • Email process_started отправлен
Дополнительные требования Доступ к SAP-сервису курсов валют и SharePoint должен быть настроен до запуска.
Возможные исключения ICS-60001-EX-01
