Идентификатор ICS-60001-Step-07
Определение Обогащение выборки владельцами и контролёром через MIM
Класс Java by.a1.ics60001.steps.OwnersEnrichmentStep
Пользователь Bot
Входные данные
  • Transaction: sample.owners (List<String>)
  • Credentials: mim_credentials
  • InitParameters: mimCommand, mimUrl, mimAccountsAttributesToGet, mimPersonsAttributesToGet, mimAccountsFilter, mimPersonsFilter, mimCommandTimeoutMs, controllerEmail
Основной путь
  1. Бот открывает PowerShell-сессию (com.profesorfalken.jpowershell.PowerShell) с maxWait = mimCommandTimeoutMs;
  2. Бот формирует и выполняет команду для аккаунтов MIM (фильтр mimAccountsFilter, атрибуты mimAccountsAttributesToGet); результат нормализуется в JSON-массив;
  3. Бот формирует и выполняет команду для сотрудников MIM (фильтр mimPersonsFilter, атрибуты mimPersonsAttributesToGet);
  4. Бот строит map sapLoginByPersonId (DisplayedOwner → vc_AppAccountName) и map personById (ObjectID → person);
  5. Бот для каждого owner из sample.owners находит personId через sapLoginByPersonId, затем person из personById; формирует OwnerContact(email, sapLogin, fullName=DisplayName+MiddleName, active = vc_EmployeeStatus == «Активен»);
  6. Бот сохраняет owners.enriched в транзакцию;
  7. Если задан controllerEmail, бот ищет сотрудника с таким Email и сохраняет controller.name (DisplayName) и controller.position (vc_JobTitleRus) в транзакцию.
Альтернативные пути Пустые owners — MIM-запросы всё равно выполняются (для обогащения контролёра). Owner без personId или без person — пропускается с логированием. При любом исключении бот выбрасывает BusinessException («Owners enrichment failed»).
Выходные данные
  • Transaction: owners.enriched (List<OwnerContact>), опционально controller.name, controller.position
Дополнительные требования На машине-исполнителе должен быть доступен PowerShell; mimCommand, mimUrl, mimPersonsAttributesToGet, mimCommandTimeoutMs обязательны (иначе IllegalStateException).
Возможные исключения ICS-60001-EX-01
