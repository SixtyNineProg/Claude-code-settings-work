Идентификатор ICS-60001-Step-09
Определение Обработка документа пользователем (web-интерфейс document-review)
Класс Java / артефакт Web-действие document-review.js (ресурс src/main/resources/actions/document-review.js); визуализация через Shadow Core Engine
Пользователь Исполнитель (владелец проводки)
Входные данные
  • Задача из очереди «ICS-60001 Document review» с тегом pendingReview
  • Параметр задачи initialData = {sampleDoc: AccountingDocumentGroup, bearerToken}
  • Ссылка на действие documentReviewActionLink
Основной путь
  1. Исполнитель открывает web-интерфейс «Обработка документа»;
  2. Таблица «Информация о документе» отображает атрибуты группы (номер документа, БЕ, валюта, дата проводки, имя пользователя, операция, признаки автоматически созданной позиции и красного сторно, вид документа, текст заголовка, код транзакции);
  3. Таблица «Позиции документа» отображает позиции (Позиция, Номер счета, Сумма ВВ, Текст);
  4. Исполнитель выбирает и загружает подтверждающий файл (обязательно);
  5. Исполнитель выбирает статус («OK» или «NOT OK») и вводит комментарий;
  6. При сохранении форма отправляет userInput = {uploadedFileGuid, uploadedFileName, status, comment} в задачу, завершая её.
Альтернативные пути Ошибка загрузки файла или сохранения результата — Исполнитель получает уведомление, повторяет попытку или обращается в support.
Выходные данные
  • Обновлённая задача в очереди «ICS-60001 Document review» с userInput (status, comment, uploadedFileGuid, uploadedFileName)
Дополнительные требования Возможность повторного открытия задания до завершения процесса; файл-доказательство должен быть сохранён в Storage Orchestrator (guid используется на шаге 10).
Возможные исключения ICS-60001-EX-01
