Идентификатор ICS-60001-Step-06
Определение Подготовка выборки для проверки
Пользователь Bot
Входные данные
  • accountingDocumentPositions
  • allowedDocList из транзакции (либо asset document_type_classification как fallback)
Основной путь
  1. Бот группирует позиции по documentNumber в AccountingDocumentGroup;
  2. Бот фильтрует группы по allowedDocTypes, оставляя только разрешённые типы;
  3. Бот рассчитывает размер выборки getDocsCountForProceed(total) (≤12 → 2, ≤52 → 5, ≤365 → 15, иначе 25);
  4. Бот случайно перемешивает индексы, берёт первые sampleSize и сортирует выборку по порядку первого вхождения документа;
  5. Бот собирает уникальные username (sampleOwners) из выборки;
  6. Бот сохраняет в транзакцию sampleDocuments, sampleOwners, filteredDocuments.
Альтернативные пути Если allowedDocList в транзакции пуст/недоступен, Бот загружает allowedDocTypes напрямую из asset document_type_classification.
Выходные данные
  • sampleDocuments (List<AccountingDocumentGroup>)
  • sampleOwners (List<String>)
  • filteredDocuments (List<AccountingDocumentGroup>)
Дополнительные требования —
Возможные исключения ICS-60001-EX-05
