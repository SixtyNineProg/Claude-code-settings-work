Описание процесса

Назначение бизнес-процесса
Автоматизация контроля корректности ручных бухгалтерских проводок: извлечение параметров, получение данных из SAP, расчёт порога существенности, формирование структуры папок в SharePoint, рассылка уведомлений и организация проверки документов с участием пользователей.

Упрощенная BPMN схема бизнес-процесса

Файл-исходник: ICS-60001.bpmn

Выходные данные бизнес-процесса
Письмо с результатами контроля; Excel-отчёт ICS-60001.xlsx; технический архив (ZIP) в SharePoint; обновлённый справочник типов документов (assets document_type_classification, document_type_comments)
