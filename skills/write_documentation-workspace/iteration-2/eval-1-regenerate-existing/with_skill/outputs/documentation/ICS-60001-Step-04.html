Идентификатор ICS-60001-Step-04
Определение Редактирование списков типов документов
Пользователь Исполнитель
Входные данные
  • задача documentTypePolicyEditor из очереди "ICS-60001 Document type policy editor" (initialData: allowedDocList, deniedDocList)
Основной путь
  1. Исполнитель открывает web-action document-type-policy-editor по ссылке из письма task_assigned;
  2. Исполнитель просматривает и редактирует списки разрешённых и запрещённых типов документов, вводит комментарии к каждому коду, при необходимости отключает типы для проверки;
  3. Исполнитель сохраняет изменения — web-action обновляет задачу в очереди тегом policyUpdated и записывает initialData.
Альтернативные пути —
Выходные данные
  • обновлённая задача documentTypePolicyEditor с тегом policyUpdated и итоговыми allowedDocList, deniedDocList
Дополнительные требования Исполнителю должны быть назначены права на папку доступа ICS-60001 и web-action.
Возможные исключения ICS-60001-EX-03
