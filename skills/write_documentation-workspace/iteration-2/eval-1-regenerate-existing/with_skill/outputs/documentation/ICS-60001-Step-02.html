Идентификатор ICS-60001-Step-02
Определение Получение данных отчёта из SAP
Пользователь Bot
Входные данные
  • resolvedReportEndDate (строка yyyy-MM-dd)
  • ExchangeRate (materialityThreshold)
  • InitParameters.sapTransactionCode, sapMocked, testExcelPath, sharepointBaseUrl, sharepointProject, sharepointBasePath
  • пути к папкам Work/Screenshots, Work/Input data
Основной путь
  1. Бот вычисляет year и month из resolvedReportEndDate;
  2. При sapMocked=false бот подключается к SAP GUI по SAP Shortcut (sap_settings + sap_credentials), запускает транзакцию sapTransactionCode, заполняет year/month/ materialityThreshold, делает скриншоты входных параметров и результата (F8);
  3. Бот инициирует экспорт (SHIFT+F9), сохраняет sap_export_*.xlsx во временную папку и завершает сессию SAP;
  4. Бот собирает скриншоты в screenshots.xlsx (Apache POI) и выгружает экспорт и скриншоты в SharePoint в папки Work/Input data и Work/Screenshots соответственно;
  5. При sapMocked=true бот скачивает testExcelPath из SharePoint и загружает его в Work/Input data;
  6. Бот парсит экспорт через Poiji в список AccountingDocumentPosition и сохраняет его в транзакцию.
Альтернативные пути Режим sapMocked=true используется для тестов: вместо запуска SAP берётся готовый тестовый Excel из SharePoint.
Выходные данные
  • accountingDocumentPositions (List<AccountingDocumentPosition>)
  • файлы ZFI_FCRP1.xlsx и screenshots.xlsx в SharePoint
Дополнительные требования На хосте Бота должен быть установлен SAP Logon 750+; библиотека sapgui должна быть доступна в java.library.path.
Возможные исключения ICS-60001-EX-02
