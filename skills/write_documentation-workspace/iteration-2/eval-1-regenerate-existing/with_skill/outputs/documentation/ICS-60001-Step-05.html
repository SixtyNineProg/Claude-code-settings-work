Идентификатор ICS-60001-Step-05
Определение Сохранение списков типов документов
Пользователь Bot
Входные данные
  • задача documentTypePolicyEditor из очереди с тегом policyUpdated (initialData: allowedDocList, deniedDocList)
  • InitParameters.emailRecipients
Основной путь
  1. Бот читает из очереди "ICS-60001 Document type policy editor" задачу с тегом policyUpdated и извлекает initialData (allowedDocList, deniedDocList);
  2. Бот собирает уникальные коды allowed и denied, формирует общий comments-словарь и собирает dictionaryList (List<DocumentTypeEntry>);
  3. Бот сохраняет dictionaryList в транзакцию;
  4. Бот обновляет assets document_type_classification (allowed/denied множества) и document_type_comments (Map код→комментарий) через orchestratorService.assets().update(...);
  5. Бот отправляет email task_completed на emailRecipients.
Альтернативные пути Если initialData пришёл как строка "[object Object]" или null, Бот бросает BusinessException — форма редактора отправила некорректный JSON.
Выходные данные
  • dictionaryList в транзакции
  • обновлённые assets document_type_classification, document_type_comments
Дополнительные требования —
Возможные исключения ICS-60001-EX-03, ICS-60001-EX-04
