Идентификатор ICS-60001-Step-09
Определение Обработка документа
Пользователь Исполнитель
Входные данные
  • задача documentReview из очереди "ICS-60001 Document review" (initialData: sampleDoc, bearerToken)
Основной путь
  1. Исполнитель открывает web-action document-review по ссылке из письма task_assigned;
  2. Исполнитель просматривает информацию о документе и его позициях;
  3. Исполнитель загружает файл подтверждающего документа;
  4. Исполнитель выбирает статус проверки ("OK" или "NOT OK") и вводит комментарий;
  5. Исполнитель сохраняет результат — web-action обновляет задачу в очереди тегом и записывает userInput (status, comment, uploadedFileGuid, uploadedFileName).
Альтернативные пути —
Выходные данные
  • обновлённая задача documentReview с userInput (статус, комментарий, загруженный файл)
Дополнительные требования Исполнителю должны быть назначены права на папку доступа ICS-60001 и web-action document-review.
