Идентификатор ICS-60001-Step-07
Определение Обогащение выборки владельцами
Пользователь Bot
Входные данные
  • sampleOwners (List<String>)
  • InitParameters.mimCommand, mimUrl, mimAccountsAttributesToGet, mimPersonsAttributesToGet, mimAccountsFilter, mimPersonsFilter, mimCommandTimeoutMs, controllerEmail
  • asset mim_credentials
Основной путь
  1. Бот открывает PowerShell-сессию (jpowershell) и выполняет запрос аккаунтов MIM (mimAccountsFilter, mimAccountsAttributesToGet) с учётными данными mim_credentials;
  2. Бот выполняет запрос персон MIM (mimPersonsFilter, mimPersonsAttributesToGet);
  3. Бот строит соответствие sapLogin ↔ personId (по vc_AppAccountName/DisplayedOwner) и индекс персон по ObjectID;
  4. Бот для каждого владельца из sampleOwners находит персону и формирует OwnerContact(email, sapLogin, fullName, active), сохраняет ownersEnriched в транзакцию;
  5. При заданном controllerEmail бот ищет персону контролёра и сохраняет controllerName и controllerPosition в транзакцию.
Альтернативные пути Если владелец не найден в MIM-аккаунтах или персонах, он пропускается (записывается в лог). Если controllerEmail не задан — обогащение контролёра пропускается.
Выходные данные
  • ownersEnriched (List<OwnerContact>)
  • controllerName, controllerPosition (опционально)
Дополнительные требования На хосте Бота должен быть доступен PowerShell и модуль Set-ResourceManagementClient для запросов к MIM.
Возможные исключения ICS-60001-EX-06
