Идентификатор ICS-60001-Step-03
Определение Подготовка списков типов документов
Пользователь Bot
Входные данные
  • accountingDocumentPositions
  • assets document_type_classification и document_type_comments
  • InitParameters.documentTypePolicyEditorActionLink, emailRecipients
Основной путь
  1. Бот загружает классификатор document_type_classification (allowedDocTypes, deniedDocTypes) и справочник комментариев document_type_comments;
  2. Бот определяет unclassifiedCodes — коды из accountingDocumentPositions, отсутствующие в allowed и denied;
  3. Бот формирует три списка allowedDocList, deniedDocList, unclassifiedDocList (код → комментарий), сортирует по коду и сохраняет в транзакцию;
  4. Бот ставит в очередь Orchestrator "ICS-60001 Document type policy editor" задачу documentTypePolicyEditor с тегом pendingPolicyUpdate и параметрами initialData, transactionName, processStage=2;
  5. Бот отправляет email task_assigned на emailRecipients со ссылкой documentTypePolicyEditorActionLink.
Альтернативные пути —
Выходные данные
  • allowedDocList, deniedDocList, unclassifiedDocList в транзакции
  • задача documentTypePolicyEditor в очереди Orchestrator
Дополнительные требования Web-action document-type-policy-editor должен быть опубликован, ссылка на него задана в init-параметрах.
