# Запуск процесса «в 8 по будням»

## Что вы просите

Запускать процесс автоматически каждый будний день в 8 часов.

## Уточнение — запрос неоднозначный

Формулировка «в 8 по будням» допускает несколько трактовок. Чтобы не гадать, я фиксирую допущения явно. Если что-то не совпадает — поправьте, и я пересчитаю выражение.

| Параметр | Принятое допущение | Если имелось в виду другое |
|---|---|---|
| Время суток | **08:00 (утро, AM)** | Для 20:00 (вечер) замените час `8` → `20` |
| Минута запуска | **ровно :00** | Нужна другая минута — задайте её первым полем |
| Дни недели | **Пн–Пт** (будни) | Сб/Вс в расписание не входят |
| Часовой пояс | часовой пояс **сервера/Оркестратора Sherpa RPA** | Если сервер работает в UTC или другом поясе — фактическое локальное время сместится |
| Праздники | **не учитываются** (в т.ч. официальные выходные) | Нужен контроль праздников внутри процесса |

## Cron-выражение

```
0 8 * * 1-5
```

Порядок полей: `минута  час  день_месяца  месяц  день_недели`.

Разбор:
- `0` — минута 00
- `8` — час 8, т.е. 08:00
- `*` — любой день месяца
- `*` — любой месяц
- `1-5` — дни недели с 1 (понедельник) по 5 (пятница)

Если нужен **вечер 20:00**, выражение такое:

```
0 20 * * 1-5
```

Если нужны **все 7 дней** (не только будни), последнее поле заменяется на `*`:

```
0 8 * * *
```

## Как задать расписание в Sherpa RPA

Расписание запуска задачи настраивается в Оркестраторе (Sherpa RPA Management Console) в свойствах задачи на вкладке расписания (Scheduler). Точное расположение элементов зависит от версии платформы, но принцип один:

1. Откройте свойства процесса/задачи в Sherpa RPA Orchestrator.
2. Включите расписание (Schedule / Расписание) и выберите режим по cron-выражению.
3. Подставьте выражение `0 8 * * 1-5`.
4. Убедитесь, что задача публикуется (deploy) с новым расписанием — иначе изменения не применятся на роботе.

Альтернативно, если в вашей версии расписание задаётся через UI, а не cron:
- Время запуска: `08:00`
- Повтор: «каждый день» / «ежедневно»
- Дни недели: отметить **Пн, Вт, Ср, Чт, Пт**

## На что обратить внимание

- **Часовой пояс.** Cron срабатывает по времени сервера Оркестратора. Проверьте его TZ — иначе «8 утра» может оказаться не тем временем.
- **Переход на летнее/зимнее время.** При смене пояса фиксированное `8` сместится на час от локальных ожиданий, если сервер в UTC.
- **Пересечение запусков.** Если процесс идёт дольше суток, включите политику «не запускать, если предыдущий экземпляр ещё работает».
- **Праздники.** Расписание «Пн–Пт» не знает о государственных праздниках. Если запуск в праздник недопустим — добавьте проверку производственного календаря в начале процесса.
- **Пропущенные запуски.** Уточните поведение Оркестратора при недоступности робота: догонять пропущенный запуск или пропускать.

## Итог

Для «8:00 утра по будням» используйте:

```
0 8 * * 1-5
```

Если имелось в виду 20:00 — `0 20 * * 1-5`. Подтвердите время суток и часовой пояс, и я дам финальный вариант без допущений.
