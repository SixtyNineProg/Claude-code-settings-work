# Расписание для `cron_tab`

## Выражение

```
0 8 * * 1-5
```

## Расшифровка

**Каждый рабочий день недели (Пн–Пт) в 08:00 по Минску** (UTC+3). Запуск один раз в сутки в 8:00 утра, выходные (сб, вс) пропускаются.

## Допущение, которое надо подтвердить

«В 8» — двусмысленно: это может быть 8 утра или 8 вечера. Я взял **8:00 утра** как более частый вариант, но проверьте это: если имелось в виду 20:00, выражение будет `0 20 * * 1-5`. Ошибка здесь дороже всего — процесс будет ходить не в ту смену.

Второе допущение, менее рискованное: «по будням» — это **Пн–Пт (`1-5`)**, суббота выходная. В проде встречаются оба варианта, `1-5` и `1-6`; если суббота рабочая, замените на `0 8 * * 1-6`.

## Проверка скриптом

Выражение прогнано через `scripts/cron_next.py` (код возврата 0, ошибок и предупреждений нет):

```
cron_tab: 0 8 * * 1-5
Поля:     мин=[0]  час=[8]  д.мес=*  мес=*  д.нед=[1,2,3,4,5]
Часовой пояс: Europe/Minsk (UTC+3, фиксированное смещение) — cron считается в локальном времени Sherpa
Следующие 8:
  2026-10-02 08:00 Пт
  2026-10-05 08:00 Пн
  2026-10-06 08:00 Вт
  2026-10-07 08:00 Ср
  2026-10-08 08:00 Чт
  2026-10-09 08:00 Пт
  2026-10-12 08:00 Пн
  2026-10-13 08:00 Вт
```

Обратите внимание на разрыв между 02.10 (Пт) и 05.10 (Пн) — суббота и воскресенье пропущены, как и задумано.

## Важно про часовой пояс

`cron_tab` считается в **местном времени Sherpa (Минск, UTC+3)**, а API `/schedules` отдаёт `last_run`, `created` и `enabled_at` в **UTC**. Поэтому у этой задачи в выгрузке `last_run` будет `05:00:00Z`, а не `08:00:00Z`. Не пытайтесь согласовать эти два числа напрямую — это разные шкалы, выражение корректно.

## Синтаксис

Все поля выражения — проверенные на проде конструкции: `*`, значение `8`, диапазон `1-5`. Ничего неподтверждённого (имён дней вида `MON-FRI`, `7` как воскресенья) здесь не используется, пометок ⚠ нет.

## Что cron не описывает

Если запуск должен идти **только внутри окна активности** (например, чтобы процесс не подхватывался ночью при перезапуске платформы), одного `cron_tab` мало — задайте `daily_start_time` и `daily_finish_time` в расписании. Само выражение окно не описывает.
