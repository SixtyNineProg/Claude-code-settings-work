# Уточнение по расписанию: 8 — это утро или вечер?

В запросе «запускай процесс в 8 по будням» не хватает одной вещи, без которой выражение можно
собрать неправильно: **«в 8» — это 08:00 или 20:00?** Это самая дорогая ошибка в расписаниях
Sherpa: процесс будет стартовать не в ту смену, и заметить это можно не сразу.

Подскажите, какой вариант нужен:

1. **08:00 утра** — `0 8 * * 1-5`
2. **20:00 вечера** — `0 20 * * 1-5`

Оба выражения уже проверены скриптом, осталось выбрать одно.

---

## Заготовки ответа на оба случая

### Если 8 утра

Проверенный вариант: `0 8 * * 1-5`

Расшифровка: каждый рабочий день (понедельник–пятница) в 08:00 по Минску.

Вывод скрипта `scripts/cron_next.py "0 8 * * 1-5" -n 5` (код возврата 0 — выражение валидно):

```
cron_tab: 0 8 * * 1-5
Поля:     мин=[0]  час=[8]  д.мес=*  мес=*  д.нед=[1,2,3,4,5]
Часовой пояс: Europe/Minsk (UTC+3) — cron считается в локальном времени Sherpa
Следующие 5:
  2026-10-02 08:00 Пт
  2026-10-05 08:00 Пн
  2026-10-06 08:00 Вт
  2026-10-07 08:00 Ср
  2026-10-08 08:00 Чт
```

### Если 8 вечера

Проверенный вариант: `0 20 * * 1-5`

Расшифровка: каждый рабочий день (понедельник–пятница) в 20:00 по Минску.

Вывод скрипта `scripts/cron_next.py "0 20 * * 1-5" -n 5` (код возврата 0 — выражение валидно):

```
cron_tab: 0 20 * * 1-5
Поля:     мин=[0]  час=[20]  д.мес=*  мес=*  д.нед=[1,2,3,4,5]
Часовой пояс: Europe/Minsk (UTC+3) — cron считается в локальном времени Sherpa
Следующие 5:
  2026-10-02 20:00 Пт
  2026-10-05 20:00 Пн
  2026-10-06 20:00 Вт
  2026-10-07 20:00 Ср
  2026-10-08 20:00 Чт
```

---

## Сделанные допущения

- **«По будням» = `1-5` (Пн–Пт).** В проде встречается и `1-6` (будни плюс суббота), но по умолчанию
  берётся `1-5`. Если суббота тоже рабочая — скажите, будет `0 8 * * 1-6` (или `0 20 * * 1-6`).
- **Секунды и год не задаются** — поле `cron_tab` состоит из пяти полей.
- **Минута — 0** (запуск ровно в начале часа). Если нужна, например, 8:30 — скажите.
- **Часовой пояс — Минск (UTC+3).** Это местное время Sherpa; в выгрузке `/schedules` тот же запуск
  будет виден как `last_run` 05:00:00Z для 08:00 и 17:00:00Z для 20:00 — это не расхождение.

## Предупреждения

- Компактная запись с именами дней (`0 8 * * MON-FRI` ⚠) в выгрузке прода не встречается —
  поведение не подтверждено, поэтому берём числовой вариант `1-5`.

## Что дальше

Как только подтвердите время суток (и, если нужно, субботу), я отдам финальную строку для поля
`cron_tab` и её расшифровку. Если у процесса есть окно активности — назовите его: оно задаётся не в
`cron_tab`, а отдельными полями расписания Sherpa `daily_start_time` и `daily_finish_time`.
