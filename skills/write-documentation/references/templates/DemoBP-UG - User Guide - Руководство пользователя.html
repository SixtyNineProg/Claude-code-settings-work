Описание шагов процесса с точки зрения действий Исполнителя

Шаг (со ссылкой на PDD) Наименование Действия Исполнителя Действия Bot
DemoBP-Step-01 Начало работы
  • Получает уведомление о начале работы процесса.
  • Бот уведомляет Исполнителя о начале работы процесса через электронную почту.
DemoBP-Step-02 Валидация параметров заказа Исполнитель не участвует (процесс выполняется автоматически)
  • Проверяет: номер заказа — числовой, количество — > 0, статус — из допустимого списка;
  • Формирует заказ для дальнейшей обработки.
DemoBP-Step-03 Обработка заказа Нет
  • Обрабатывает заказ;
  • Сохраняет результат обработки для отчета.
DemoBP-Step-04 Завершение работы
  • Получает письмо с результатами работы Бота.
  • Бот формирует письмо-отчет с описанием результатов работы;
  • Бот отправляет Исполнителю письмо через электронную почту.

Работа Исполнителя с исключениями

№ Описание Тип исключения Действие Исполнителя при наступлении
DemoBP-EX-01 Неизвестная системная ошибка Системное
  • Получить уведомление об ошибке: "Ботопроцесс DemoBP. Во время выполнения ботопроцесса возникла ошибка. Ботопроцесс остановлен."
  • Ожидать информации от support группы по решению проблемы в рамках задачи RPA либо скоординировать действия по данному вопросу самостоятельно.
