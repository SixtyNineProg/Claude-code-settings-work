Общее описание

Процесс "DemoBP" предназначен для пробной демонстрационной работы бизнес-процесса на платформе Sherpa RPA, а также для создания образца документации для использования в других ботопроцессах.

С целью трассировки требований общим артефактам по данному процессу присваивается индекс "DemoBP".

Документация по роботизируемому процессу состоит из следующих разделов:

  • DemoBP: История изменений
  • DemoBP: Инструкция по развертыванию
  • DemoBP-PDD: Process Design Document / Документ проектирования процесса
  • DemoBP-TD: Test Documentation / Тестовая документация
  • DemoBP-UG: User Guide / Руководство пользователя
