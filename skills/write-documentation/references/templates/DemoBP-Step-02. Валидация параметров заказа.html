Идентификатор DemoBP-Step-02
Определение Валидация параметров заказа
Пользователь Bot
Входные данные
  • конф. параметры ботопроцесса
Основной путь
  1. Бот извлекает из конфигурации значения: orderId, orderAmount, orderStatus;
  2. Бот проверяет корректность значений (orderId — числовой, orderAmount — > 0, orderStatus — допустимый);
  3. При успешной проверке Бот формирует объект Order для дальнейшей обработки.
Альтернативные пути 3. Если значения некорректны, Бот отправляет нотификацию с описанием проблемы и выбрасывает ошибку;
Выходные данные
  • Order - заказ, готовый для обработки
